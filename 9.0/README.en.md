# AI Drama Director Skill · AI短剧导演 Skill｜9.0

**Author: mr zhu · [中文](README.md)**

A self-contained course for an agent with no project memory: learn the directing method, read the current script, analyze characters and locations, review applicable content risks, stage action and space, choose coverage, form generation groups, write concise prompts, and check performance and every cut. The script and user decisions establish the facts; the skill supports shot choices.

Version 9.0 develops continuity between independently generated groups, character-specific performance, emotional progression across a scene, and coverage choices in the context of adjacent shots. A simplified 3D location reference is optional. Ask once if its availability is unknown; use supplied references, or draft a plausible layout and deliver the complete storyboard before asking about the proposed layout. Creating a 3D image requires an explicit request. A complete fictional scene includes its source, layout, emotional progression, five executable groups, and all 19 adjacent-cut checks. The main Markdown contains all teaching, 33 figures, and 11 complete examples.

Generation groups total 1–30 integer seconds; internal cut points may be fractional. Preserve source dialogue, relationships, and events. The current workflow uses Seed2.5 original audio and adds background music in post. The three-second limit on continuously visible mouth-to-mouth kissing is a project rule, not a universal platform regulation.

Fictional teaching diagrams do not replace production references or prove generation reliability. Text, arithmetic, geometry, reading-package validation, and actual video/audio tests are distinct.
