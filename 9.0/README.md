# AI短剧导演 Skill｜9.0

**作者：mr zhu｜[English](README.en.md)**

让没有项目记忆的写作AI先学导演方法，再读剧本，分析人物与场景、完成审核预检，安排行动与空间，排镜分组，精简提示词，检查情绪及全部镜头衔接，输出可逐组使用的完整分镜。剧情与用户决定是事实依据，Skill辅助选择拍法。

9.0重点教跨组人物起态、人设对应的表演、整场情绪发展与邻近镜头覆盖。简易3D场景图可选：制作前一次确认未知情况，有图按实际，无图正常拟定并交完整稿，交付后确认拟定布局；制图需用户明确提出。整场虚构实战包含源文、布局、情绪、五组提示词及19处相邻镜核查。全部必要教学、33图和11套完整示例均在主MD。
