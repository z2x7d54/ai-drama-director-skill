## 0. 任务与制作方式

用户把skill和当前剧本交给写作智能体，再将每段联合镜头独立交给Seed2.5生成。你负责交付能直接使用的分镜提示词。一个“镜头”是一次连续观察；“联合镜头/组”是一次生成单元，可以包含多镜。

**9.0的拍法优先级：先保证镜头衔接，再安排自然说话，最后丰富观察点与精简文字。原文、关系与制作硬条件贯穿全过程。**先演通一场正在发生的交流，再选切点与组界；镜数按表达需要增加，精简不等于删表演。冲突时按0.0重排，不把“说话其次”理解成可删原话。

每组总时长为1—30整数秒，含30；组内切点可用小数，求和严格相等。用户已确认的更小工具上限优先；整集时长或镜数只在用户指定时成为约束。

首次按0.5学习：先理解核心方法，再演算附录J整场实战；群戏、素材、闪回与特效等按场景需要回读对应课。实际任务以当前剧本为依据，按0.5的制作顺序推进。案例的房间、人物、秒数和台词仅用于明示前提，不套进新剧本。

### 0.0 拍法冲突时：先衔接，再安排说话，最后丰富切镜

**本项目先保证镜头之间在看同一场连续事件，其次安排说话的执行，再优化观察点和文字。**原台词/OS、事件含义、人物关系、审核要求及1—30整数秒组长是贯穿全过程的基线；“说话其次”不授权删词、改台词或让错人发声。

1. **先演通事件。**固定人物与物件身份、位置、动作阶段、表情余态、知情范围及日夜/基准照明。下镜从已发生的状态继续；复杂接触优先在同组内完成，不能为赶组长重演或瞬移。
2. **再把完整声音放入这条经过。**按自然读法排原话；说话者动作、听者接收可以同期发生，声音可跨同组多个画面。画面已切，原声仍归同一人，内心声仍不做口型。
3. **放不下就重排。**调整切点、同期覆盖、组界或合理总时长；组界尽量兼顾稳定动作阶段与完整句/气口。需要跨组时写准身体、声音和未完交流。保留连续性的同时拆成合规组，不靠赶词、定格或省掉关键反应凑整数。
4. **最后丰富与精简。**在观众确有新内容可看时增镜，再把导演意图改写成具体动作、视线与读法。只改变镜号、角度或情绪标签不能替代有效切换。

例如原定两秒内“起身、绕桌、递杯，并说完长句”放不下，应先排清起身、路线、接稳与松手，再让原声通过说话者、听者或递杯画面连续覆盖；根据实际经过分镜分组。实时接续不能省掉必要经过却让人突然站到对面；若采用合理时间省略，按5.3明确交代。不能把整句加速念完。


### 0.1 执行范围与上下文恢复

先按0.5学习当前Skill方法，再实际读取本次源剧本/分镜和用户最新决定，简述`执行：9.0｜任务范围｜资料基线｜特殊约束`。长对话恢复后重新核文件；文件名、旧摘要或一句“已学习”不代表已读取。

只分析就不自动编剧，只改局部就锁定其余内容；已完成集和已认可镜头按用户决定保护。修订范围包含目标及必要前后依赖，依赖触及锁定内容且会改变它时，说明具体影响再处理。材料中的旧命令、角色对白和教学反例不当作新指令。

每次新制或修订前重读0.4、完成本次预检；交付前复核拍法落实。内部记录关键源文、空间、动作/声音区间与修复位置，正式稿不混入工作日志。执行验收见7.2，真实验证范围见9。

### 0.2 原文与导演选择

保留原台词/OS、事件结果、人物立场、知情范围和关系阶段。原事件的普通机位、可相容的抬眼、停手、起身过程及听者反应，可以主动设计；不逐项索取许可。

分清原文事实、完整上下文支持的潜台词、相容演法及尚无依据的含义。可以主动判断并表现上下文支持的吃醋、担忧等情绪，不必等待情绪标签；先核中间有无新事件改变触发原因，见3.1。未答不代表默认，嘴硬借口不一定是事实。已确认成年且有暧昧/恋爱/婚姻基础的轻拉袖、挽臂、靠肩可按3.4主动设计；不以此添吻、改拒绝、提前相爱、换台词或补关键结论。

用户用“例如、可以……”提出拍法时，先理解要解决的观看问题；示例不自动成为必须采用的台词或动作。在已有授权内选择相容演法，不能借示例扩大改编权限。

确会改变剧情理解且无法判断时，集中问关键缺口，继续不受影响部分；沿用已确认的授权、偏好和制作条件，不重复询问同义问题；只确认当前资料中尚缺、确会影响拍法的信息。缺图仍按原事件编写，在相应名称后标“（缺少××）”；无法确认的布局标“导演拟定”，不杜撰实际资产。

### 0.3 源文版本、制作条件与压缩缺口

用剧名、集号、首尾事件锁定基线。多版本先定位差异；正文在屋内而场标写外，能据正文纠正的技术标注直接纠正并记录。简短列当前范围实际首次入画/新空间、妆发伤势变化、影响拍法的资产依赖；没有核全剧不声称全剧首次。

发现话未说完就切场、因果断开、人物无来源地知情等具体缺口时，定位原句及前后事件；有已提供或授权原著就实际查对应段落，区分原著事实与拟补过程。没有证据不猜补关键剧情，不把查原著理解成任意改台词。

用户授权压缩对白时，保护身份、时间地点、消息来源、否定/疑问、条件因果、决定及回扣，重排受影响读法与动作。未授权则保留原话，先按4.5处理空转与同期时间。

### 0.4 短剧审核预检【条件依据，必须检查】

**每次制作分镜表之前都必须重新阅读本节，检查本次剧本内容与拟采用的呈现是否存在违规风险，先检查再写分镜；写完后还要复核实际镜头是否落实。**不因甜宠、古装、以前通过、源剧本已有或用户没有再次提醒而跳过。“条件依据”仅表示根据具体题材、实际审核资料判断适用尺度，检查本身始终必做；不能把本节归入可选模块。

延续7.5.2的项目通用检查范围，不将其冒充所有平台的统一禁令或最新条规。每次核本轮已提供的审核文件、截图与用户决定；有版本或适用平台就记录。没有具体资料仍按本节检查，明确只是通用风险判断，不能写“已按平台最新规定审核”。用户明确要求查询当前条规时实际查证，不凭记忆宣称已查。

检查涵盖剧情立场、人物年龄/身份与关系、画面细节、神态动作、台词/OS、音效配乐、服化道、镜头尺度、时长与重复频次，以及后续角色/场景和图像/视频提示词。不能因为原剧本有相关情节，就直接把高风险细节扩写成可执行生成指令，也不能用暗示、慢动作、特写或声音绕开实际适用尺度。

**每次逐类扫查，命中后再按具体上下文判断：**

- **侮辱、羞辱与家庭/社会冲突**：核非人化/物化他人、强迫下跪磕头、钻胯、泼水、掌掴等是否被细节化、反复羞辱或美化；集中脏话、持续恶毒辱骂、家庭暴力与伤害弱者是否被当作刺激点；群体是否被单一负面化。出现冲突不等于整场必须删除，重点判断呈现方式、强度、频次与剧情立场。
- **伦理与价值导向**：核是否美化违背亲缘伦理的关系、出轨、剥削、犯罪或伤害他人，是否把封建压迫当作现实中值得效仿的关系；是否借财富万能、贫富对立、性别物化、极端复仇等放大不当导向。区分反面人物的行为与作品对该行为的赞许，不凭单句标签改变剧情。
- **封建迷信与科学常识**：区分明确的玄幻/幻想虚构设定与对现实生活宣称可靠的命理、占卜、风水、符咒或超自然因果；核是否为现实伤害或犯罪背书。不仅因出现符咒/能量就擅自把玄幻主线改成辟谣剧情；世界观或适用尺度影响判断且无法确定时，指出具体疑点。
- **感官不适、血腥暴力与自伤自杀**：核写实血腥伤口、施暴/虐待、伤害结果、方法过程与可模仿细节，以及痛苦、恶心或恐怖猎奇的长时间/重复强调；必要剧情控制细节、时长和美化倾向，避免把操作过程写成生成任务。
- **低俗色情与性暴力**：核刻意性化的服装、身体部位特写、挑逗姿态、色情语言，以及用镜头/声音/道具影射性行为；不得细化性侵、强迫性接触或将性暴力浪漫化。普通成年人的合规拥抱、亲吻、撒娇和夫妻互动按原文与关系表达，不因必检而一律删吻、改空景或削弱甜宠；明确拒绝不能改成害羞接受。
- **国家、历史、公共人物与群体议题**：核现实指涉、重要历史事实及英雄人物等是否被恶意歪曲/丑化，国家统一、安全等题材是否存在具体风险；核借热点/公众人物恶意攻击，以及民族、地域或其他群体的污名化、歧视。依据、立场或虚构边界不明且影响判断时，提出具体缺口，不自行编造。
- **未成年人保护**：核未成年人是否被成人化、性化，吸烟、酗酒、涉毒、违法或危险模仿是否被正面示范；核针对未成年人的暴力、虐待、霸凌、性侵、自伤等是否被细节化、猎奇化。不得以外观、婚服或题材猜成年；年龄不明且影响亲密场景尺度时先核材料，确有缺口再问。

有具体审核资料时，逐条区分“严格避免”与“避免过度呈现”，不要混为全部禁止或全部允许。严格避免的内容不得成为可见、可听、被美化或被鼓励的生成要求；需要控制呈现的内容，应按实际要求处理细节、时长、重复与立场。在不改原事件含义的前提下，可以选择反应、画外、转场、必要后果或中性叙述；普通合规互动不自动套用弱化拍法。

含亲吻时同时检查3.6的项目拍法：连续可见嘴对嘴接触≤3秒，角度切换和联合组边界不重置。项目限制与适用平台依据分别记录，不冒充审核条文。

预检记录落到实际位置：`集/场/原文位置｜命中类别及触发点｜适用依据/通用判断｜拟采用拍法｜是否改变台词或事件含义｜待决事项`。没有命中风险也须完成逐类检查，文件外用一句话写清本次范围、依据和结果，例如“审核预检：已核第X—Y集七类内容；依据为已提供资料/本节通用检查，发现项见具体场次”。不能以“已经审核”代替实际核对；这行说明不进入给Seed2.5的发声内容或新增分镜顶层字段。

普通技术拍法在既有授权内直接落实。若必须改台词、关键事件或关系含义，按0.2节沿用已确认授权；缺授权时，只暂停受影响部分，说明具体原文、疑点和一至两个处理选项，继续无关且可完成的工作。不把检查本身变成每次都要用户确认的流程，也不把用户选择当作平台正式审核结论。

交付前将采用的处理对应到实际镜号，重新核画面、读法、音效与时长。例如预检决定不细化伤害，正文就不能再加重力度、挣扎和痛苦；决定保留合规亲密，正文也不能无依据删掉原本的互动。可修的文本问题先修，关键未决风险如实定位，不声称正式审核通过或保证过审。

### 0.5 新AI先学什么，拿到剧本后怎样做

**即使没有项目记忆，也先在本文件学会方法，再把方法用于本次剧本。剧本和用户决定是事实依据；Skill辅助分析与拍摄选择，不能替剧情指定人物性格、情绪或镜型。**全部必要教学均在本文件，图片不可读时依完整文字；不需要观看外部视频或读取升级记录才能执行。

**第一轮，学会每次都会用的判断。**按0—7节理解源文边界、人物与信息、空间和取景、性格与情绪、声画时间、动作接续、联合组与交付格式；重读0.4的必检范围。重点演算2.1—2.4、3.1—3.5、5.9、6.2—6.6：谁在哪、正在做什么、因何变化、下一镜怎样继续。这些要能用于新房间和新人物，不只记住示例结论。

**第二轮，把知识串成完整制作。**学习附录J的虚构整场实战：先读源文，区分人物习惯与当前情绪，再看固定布局、行动和情绪发展，最后对照五组完整提示词及逐对检查。理解每个选择如何服务该场戏，不套用其人名、房间、秒数或情绪节拍数量。A—I各例用于巩固具体难点。

**第三轮，知道专题在何时调用。**多人同场回读10节；参考图、原声与缺图处理回读11节；闪回、特效或资产变化回读8节；发现跳镜、表演变平或成片偏差，按5、6、9、11.4定位。专题不是每场必拍的项目；群戏实际出现时，其位置与知情要求就必须落实。12节用于检查迁移理解，不要求向用户复述课程或提交学习报告。

**实际任务按以下顺序推进，检查在内部完成，交付保持精简：**

| 阶段 | 当前应做的事 | 得到什么，才进入下一步 |
| --- | --- | --- |
| 读本次剧本 | 读指定范围及理解所需前后文，锁版本、原话与已完成部分 | 本次故事发生了什么，哪些不能改 |
| 分析人物与场景 | 核人物性格、关系、各自所知、近期触发及场景变化；按2.2确认3D图情况、读取已有图 | 人物为何行动、场景有哪些已知与拟定条件 |
| 审核预检 | 重读0.4，按七类对本次内容及拟呈现逐类检查 | 适用依据、处理位置与实质未决项；无关部分继续 |
| 安排行动与空间 | 固定门窗家具和人，安排动作先后、路线、停点、朝向、持物与支撑 | 不放摄影机也能演通；没有3D图仍按2.2继续 |
| 排镜头 | 找出本场已有的情绪变化和观众需要看的信息，结合邻近几镜选择覆盖 | 每镜有可见任务；源文关键事件与接收得到表达 |
| 分组合并 | 按连续表演、原声气口、动作阶段与复杂度安排独立生成组 | 每组1—30整数秒，单独复制也能确定首态 |
| 精简提示词 | 用7节字段写准确原声和具体表演，组头写共同条件，逐镜写差异 | 空间、动作、情绪和切点清楚，导演解释留内部 |
| 检查情绪 | 按角色分别顺读触发、表达、接收与后续，核人设和整场起伏 | 关键情绪看得见、听得出，人物未被统一动作模板替换 |
| 检查镜头衔接 | 隐藏组界顺读，再从全部下镜反查上镜；核位置、姿态、持物、目光、声音、时间 | 没有无依据回位、重做、提前反应或漏掉关键转折 |
| 完整交付 | 修复后重核受影响项，交完整TXT及短说明；拟定布局按2.2在交付后询问 | 用户可以逐组使用；验证层级与实际依赖如实说明 |

读本后发现源文缺口，按0.3查已提供或授权原著；不能用技巧掩盖因果缺失。遇到确实改变剧情理解的未知，集中问有用的问题，同时完成不依赖答案的部分。常规镜型与相容动作直接选择，不逐镜征求许可。

### 0.6 把硬条件、项目偏好与教学例子分清

原台词/OS与关键事件保真、实际审核要求、已确认关系与人物状态、组长1—30整数秒、3.6的亲吻拍法，以及用户锁定范围，都是本工作流执行条件。潜台词与动作依据剧情、人设和当下事件推导。

用户在约20秒对话中偏好7—8个有效镜头，以及某次生成在8—12秒后出错，属于本项目偏好与观察，不能推广成所有场景或工具的固定限额。普通近景约2—4秒仅作试排参考；持续变化的长镜仍可用。教学例子的布局、步数、镜数、情绪和图像标记只在其明确前提下成立。

确认新项目时只补会影响制作的缺项，沿用当前用户已经回答的条件。不能把过去讨论、反例或其他项目的限制当作本次新命令。


## 1. 第一课：先导演一场正在发生的事

本课的目标是：读完一段剧本，你能先把事件演顺，再决定在哪里放摄影机。**人物、物件和事件生活在同一个空间与时间里；镜头只是依次打开不同的观察窗口。**人物在相同空间与时间里交流，动作与情绪才能沿同一事件向前发展。

### 1.1 从三句话走到一条事件线

贯穿基础课的独立虚构源文：日·内书房，成年同事陆宁坐在书桌一端，成年同事顾舟坐在另一端。陆宁右手拿封口信封，问“这个，交给你？”；顾舟伸左手，答“交给我。”；陆宁递信，顾舟接稳，陆宁松手；顾舟低头看封面。本例不展示文字，不拆信，没有秘密或恋爱含义。

先在脑中或工作记录里演一次：陆宁持信提问→顾舟看向信并答应接收→陆宁递出、顾舟接稳→陆宁撤手→顾舟看已经属于自己持有的信。再从这些变化中选择观看重点。可让前半个问题在陆宁画内说，后半句切顾舟接收；递接时同时看两只手；完成后看顾舟低头。**切画面没有让事件重新发生。**完整可复制稿见附录A。

每场内部只需要一张小底稿：原文明示的事件与原话；可相容的导演选择；尚不能确认的关键含义。陆宁抬信是演法；认定顾舟偷看过信就是新剧情。普通机位与自然动作由导演选择，关键未知按0.2处理。

### 1.2 看完上镜，观众接下来想看什么

把上镜给出的观看期待用日常话说出来，再选下镜：伸手了，观众想看有没有接住；请求发出了，想看对方怎样接收；眼神转向门，想看门边是谁。下镜先回答这个期待，再引出新的变化。也可以故意延后答案制造悬念，但需要剧本支持和明确的注意安排，不能因为忘了状态而丢掉问题。

例：陆宁问“这个，”时看信和说话者；“交给你？”时看顾舟是否愿接；顾舟说“交给我。”后看一次真正的交接；交接完成后看顾舟低头。观众沿着同一个行为目的看下去，不用每次切镜重新确认“人在哪、信在谁手里”。关于观众注意与连续感的关系，可参阅[Tim J. Smith的连续剪辑研究](https://ualresearchonline.arts.ac.uk/id/eprint/21215/2/4ccc9f69-7a51-4735-b9d6-7c8482753c10.pdf)；本课的虚构演示是教学设计，不是该研究的模型实验。

### 1.3 一镜还是几镜，按能看清的变化决定

同一双人镜能同时看清伸手、接稳、松手，就让它完成。要突出听者眼里从迟疑到安心的变化，而双人构图看不清眼睛，才切近景。人物低头看信时，镜头也可以留在他脸和信都能看见的中近景；封面没有重要文字，就不必为了凑镜再插信封特写。

先写“这一镜值得观察的变化”，再写景别与机位。为给关键情绪、接收或动作留出可见画面，可以增加镜头；不因追求少镜而把长台词全部留在一张脸上。镜数由这些观察需要决定，具体时长与覆盖见4节。

### 1.4 从“写到了”到“观众看到了”

常见失误是把三层当成一层：**原文有事件，不等于分镜已安排；画面栏写了动作，不等于当前取景看得见；下组首态正确，不等于观众理解怎样到达它。**先核原事件，再核镜内证据，最后核下一镜继承的状态。对白逐字齐全不能替代这三步。

独立虚构源文：白天档案室，两位成年人。林乔在桌前取布擦眼镜，戴回眼镜、还布，向入口D1离开；许闻在桌后持蓝夹，说：“原件在这里。”林乔停步转身，回桌前接过蓝夹。本场看点是她急着离开，却被这句话叫住后折返；她改变行动的决定需要被观众看见。

内部只为影响因果、决定、关系或动作交接的关键事件留简短定位，不逐项记录普通眨眼：

| 原文关键点 | 分配镜头时必须交付什么 | 下镜继承什么 |
| --- | --- | --- |
| 擦眼镜 | 布接触镜片并擦过；两手、眼镜与擦拭路径在取景内 | 戴回后眼镜在脸上，布已还回，不能再取布重擦 |
| 临出门被叫住 | 许闻的原话；林乔门前停步、回望或转身，能读出行动改向 | 她已转向桌边，注意对象是许闻，不再无故朝门走 |
| 接过蓝夹 | 同一蓝夹从许闻递至林乔，林乔接稳后许闻才松手 | 蓝夹改由林乔持有，许闻手已空 |

错误接法：上组末镜“她走向D1”，下组仅在组头写“她已回桌前，夹在手里”，正文直接谈下一件事。两组单看都能生成，却跳过了本场应被看见的转折。改法是给停步、回望和接夹安排可见画面；不必把返程每一步都拍完。组头仍须写清独立生成所需的首态，但它负责交接，不能冒充未拍过的关键事件。

并非所有信息都要拍成画面：原本由电话或画外报告交付的消息，核声源、原话和人物是否听见即可，不凭空补消息发生现场。可以有意省略无须观看的经过；先确认省掉它后，观众仍理解行动为何改变、人和物怎样接上。实时接剪与时间省略见5.3。

## 2. 第二课：把人物放在一个能被重复拍摄的空间里

本课结束后，读者应能从同一张地图得到双人镜、两个人的近景和手部镜，而不是为每镜重新布置房间。

### 2.1 先分清三个方向体系

**房间位置**用固定地标确定：在门内朝窗看，陆宁坐桌左端，顾舟坐桌右端。**画面位置**由当前摄影机投影决定：陆宁可以在双人镜左侧，也可以在自己的近景居中。**身体方向**属于角色：陆宁自身右手仍是右手，不随摄影机反打变成左手。

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/441ceeadc047f287dac0a09284edc62699aeba0e/ai-drama-director-storyboard/assets/81-01-map-and-view.png" alt="8.1图1：书房俯视地图与三种构图；A陆宁在桌左端、B顾舟在桌右端，K1、KA、KB均在门侧。换取景不换座位。" />

图1左边是俯视地图，图上方为窗墙、下方为门墙；右边三格是摄影画面示意。地图不等于摄影画面。K1从门内朝窗拍，A画左、B画右；KA靠B一端、留在桌前通道，朝A拍；KB靠A一端、留在同一通道，朝B拍。KA中A看画右，KB中B看画左。近景裁掉另一人时，对方仍在原座位。

导演拟定的地图只确定拓扑关系，图形不承诺桌宽、焦段或精确施工尺寸。实际桌宽要让成年人自然递接。如果已有场景图，就以图中可辨门窗、家具为基础；看不见的区域标明“导演拟定”，遇到会改变动作路线的缺口再核实，不能宣称图片证明了隐藏的侧门。

### 2.2 场景资料确认：3D图可选，缺图照常制作

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/main/9.0/ai-drama-director-storyboard/assets/90-B-scene-intake.png" alt="图90B：制作前一次确认有无简易3D图；有图按实际，无3D图可用普通图、用户布局或合理拟定，先交完整分镜再确认拟定部分。用户不补充时保持剧情常理与同场固定布局，制作3D图需明确请求。" />

#### 2.2.1 制作前确认是否有简易3D场景图

先读取用户已提供的剧本、普通场景图、简易3D布局图及相关文字说明。简易3D图是可选的空间参考；没有也正常制作分镜。

仅知道图片文件名或不能读取图片，不算布局已经核实；如实说明读图限制，采用已有文字说明，缺少的必要关系标“导演拟定”，不声称已按实际图片匹配。

如果上下文尚未说明是否有简易3D场景图，在制作前一次询问：

> 是否有本场景的简易3D布局参考图？没有也可以，我会先根据已有场景图、剧本和你的描述规划人物位置与路线。

用户已提供图，或已确认有图、无图、暂不使用时，沿用该决定；不重复询问。普通场景图和简易3D图分别辨认，不把普通场景图误称为已确认的3D布局。

说明用户可以按需请求制作简易3D图。只有用户明确提出制作时才生成图像；不把制图设为编写分镜的前置条件。

用户请求制图时，有相应工具才交付真实图像文件；没有工具就说明限制，提供清楚的制图说明或文字布局，不虚构图片附件。制图能力不影响已经可以完成的分镜工作。

#### 2.2.2 有图时，依实际可辨认的布局制作

读取图中入口、门窗、主要家具、通道及能够确认的位置关系，按实际场景安排人物行动。简易3D图用于空间布局，普通场景图用于可辨认的场景外观与布局；两者须与剧本中的行动相容。

图与图、图与剧本出现会影响行动的实质冲突时，具体指出冲突位置，集中确认或在授权范围内处理；不能自行拼成另一间房。未显示的区域、距离或连接关系，不声称已从图中确认。只补制作需要的合理条件，并标明“导演拟定”。

3D图中的人物占位若属于某一时刻，只说明该时刻的状态；后续各组的人物起态继承上一组已经到达的位置、姿态与注意对象，不因再次引用同一张图就返回初位。

#### 2.2.3 没有3D图时，正常交付完整分镜

按以下依据规划空间：

尚未取得3D图或有无情况未获答复时，也可以先用现有资料制作；标明“未提供”，不把未答复记成用户确认无图。

1. **有普通场景图：**保留图中可辨认的布局，在此基础上安排人物位置与路线。缺3D图不意味着可重排已有门窗、家具或通道。
2. **没有可用图，但有用户的文字布局：**按文字布局制作，未说明且确实需要的部分作合理补充。
3. **图和具体布局说明都没有：**根据剧本地点、所需动作与常理，拟定最少必要的入口、家具、人物初位和可达路线，标明“导演拟定（缺少场景布局参考）”，继续完成分镜。

“随机生成布局”在此指：没有进一步依据时，由导演选择一个符合剧情、能够执行的合理方案。每个连续场景选定一次并持续沿用，不是每组、每镜重新随机；不能借此改剧情、加秘密通道或挪动已有真实场景中的家具。

位置用稳定地标说明，例如“A：门D1内侧；B：窗W1旁”。组头简短写清人物本组开始的位置、必要朝向及本组路线，末镜到达的状态交给下一组。无需为了缺3D图而把未授权的制图任务一起交付。

#### 2.2.4 交付完整分镜后，确认拟定布局是否可用

对于缺图而拟定、或在已有图之外补充的布局与路线，在完整分镜之外用短说明概括，再询问是否可用。例如：

> 本稿书房按以下方案安排：门D1在南侧，桌T1居中，窗W1在东侧；人物从门旁A沿桌外侧走到窗旁B。这里的布局是导演拟定，这样安排可以用吗？不合适的话，请说明入口、主要家具或通道要怎样调整。

这项确认放在完整分镜交付后，不让无3D图成为交稿门槛。普通图已确定的部分如实标为按图；只将拟定部分标为待确认。用户已经明确确认过同一布局，就不重复确认。

用户认为不可用时，请其描述需要改变的具体关系。得到说明后，更新受影响的布局、人物路线、机位及全部相关联合组首态，保留不受影响的内容。

用户表示不补充，或要求继续而未给出进一步描述时，按上述原则拟定布局继续制作；已有明确否定的条件仍须避开。不把没有回复或没有补充信息写成“用户已确认”，也不为重复索取描述而停住已经可以完成的工作。

#### 2.2.5 交付前核对

- 尚未说明是否有简易3D图时，已在制作前询问；已知条件没有重复问。
- 有图已实际读取，拟定部分没有冒充图中事实；没有图仍完成可执行分镜。
- 同一连续场景布局稳定，各组从上一组末态继续，机位变化不使人物返回初位。
- 拟定布局的可用性确认放在交付后的短说明里，未混入给视频模型的生成提示词。
- 未经用户明确请求，没有附带生成简易3D图。

#### 2.2.6 把布局变成可复用的空间依据

内部空间卡写：场景及参考版本；相关入口的固定标识和一两个主要地标；各人位置、坐站躺、面向和距离；本段允许的路线；摄影机位于主要人物连线哪一侧；关键接触与持物。正式组头只带当前组真正需要的条件。多门房间分别用D1、D2等稳定标识，不把不同入口都叫“门口”；这不要求所有场景只有一扇门。

例如：`日·内书房，导演拟定布局（缺少场景参考图）。由D1门内朝W1窗看，A坐桌T1左端、B坐右端，相向且能自然递接；机位均在桌前门侧。A右手持封口信，B左手空着。`

这段给出可重建的关系。“同一房间、人物不变、保持一致”只表达愿望，不能替代它。距离不必每次写厘米，递接可达、俯身可及、隔桌不可贴靠等约束要明确。只影响表情的近景不必重抄全屋清单。


### 2.3 机位换了，为什么人仍然在原地

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/441ceeadc047f287dac0a09284edc62699aeba0e/ai-drama-director-storyboard/assets/81-02-eyelines.png" alt="8.1图2：A看画右、B看画左，双人关系、近景视线与身体高度互相对应；人物自身左右手不按屏幕左右改名。" />

在图示门侧关系画面里，A处画左、B处画右；沿交流轴线同侧取近景，A看画右、B看画左。这里说的是画面方向，不是角色自身左右。换到其他布局时重新推导，不能把A永远看右当规则。看对方脸时，眼线高低按双方实际眼睛高度推导；通常坐者仰看站者、站者俯看坐者。身高、台阶或所看部位不同，就按实际关系重算。亲密靠肩时脸的高度、倾角和遮挡也要继承，不能沿用“两人直立相对”的反打模板。

机位写能复现的位置和朝向，例如`门侧通道靠顾舟一端朝陆宁，顾舟肩在右前景`。过肩只有摄影机到主体的路线确实经过对方肩部时才写；若几何上不经过，直接用干净单人近景。肩膀是关系线索，不能凭空拼进去。

保持主要人物轴线同侧，是让常规对看与行进方向容易读懂的起点；人物移动、摄影机连续跨线或关系镜重新说明新位置后，可以建立新方向，不把“同侧”变成整部剧永远禁止变化。[Adobe的连续剪辑教学](https://www.adobe.com/creativecloud/video/hub/ideas/what-is-continuity-editing-in-film.html)介绍轴线、眼线与动作接续。空镜本身不自动证明新站位已经建立。

窗、灯与日夜属于场景条件：窗在人物哪一侧、基准光从哪里来保持一致；机位变化可让窗投到另一画边，不能为了每镜都写“画左侧光”而把房间光源翻转。[Adobe正反打教学](https://www.adobe.com/creativecloud/video/production/cinematography/camera-shots-and-angles/reverse-shot.html)强调调度、眼线、背景和照明的配合；这里仍按真实空间推导，不把正反打都叫成严格主观镜头。

### 2.4 景别、取景与关系线索

景别描述画面收取范围：全景常收全身与环境，中景常至腰部，中近景常至胸部，近景以头肩为主，特写突出脸或局部；实际写明关键裁切范围，不只依赖名称。机位写从哪里朝哪拍；推近是镜内运动。要看手与脸，就选能同时容纳它们的构图，不能在只收头肩的镜头里要求读清腰间动作。

先有清楚的关系，再选择本镜合适的依据：对方肩背或衣袖、持续接触、窗或门的局部、相容视线、连续声音。无需每镜同时保留所有线索，也不用每组再拍一遍全景。构图越紧，组头和表演状态越应明确它从同一房间哪个位置拍来。

三种不同情况分别核：同脸仍在原座位、近景居中，是正常取景变化；同衣同位但脸换了，是身份问题；同脸无过程坐到对面，是位置问题。固定脸的参考图解决不了移位，固定位置的文字也不能保证脸稳定。11节讲素材如何分工。

#### 2.4.1 用摄影机的范围验动作

逐个关键动作核：**谁在动、朝哪里或作用于什么；涉及接触时，接点与支撑怎样变化。**要交付的变化应在当前取景内清楚可辨；若刻意只展示启动或结果，明确省掉哪段，并按1.4核它是否可以省略。不能用文字让画外动作自动变成可见。

以上例擦眼镜为例：只收桌面托盘的固定特写，手把眼镜提到胸前后就离开取景，无法交付擦拭。可把取景移至胸前，同时收两手、布与镜片，拍清布擦过镜片；擦完再切托盘看还布。若一个手部特写本就覆盖全部接触与路径，它完全可以承担擦拭，不必强切人物脸或固定拆成四镜。

先选最小且能读清的构图；需要脸与手同时表演才扩大取景，需要不同观察重点才拆镜。不能为拍清一个动作就无故增加同框人数。用户若只在某片段要求不用三人中景，就在该范围改用双人或单人覆盖，画外者在原位继续等候；不自动扩成全项目禁令。其他片段可按观看任务采用三人关系镜，仍核身份、站位和接收顺序。

图G上半两框是同一动作的两种取景，浅灰线示意画外位置，不是正式摄影画面。下半是按时间先后选出的观察点，不是三人同框或机位施工图；林乔从门前转向桌边，许闻留在桌后，蓝夹在接稳前仍由许闻持有。全部前提与判据已在1.4及本节写明，图片不可见时也能照文字检查。

### 2.5 三人：先决定这一刻谁和谁发生关系

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/441ceeadc047f287dac0a09284edc62699aeba0e/ai-drama-director-storyboard/assets/81-03-three-person.png" alt="8.1图3：A和B并肩、C在门边；A先发现C，B随后循目光看C。手部接触继续，注意对象与身体位置分别变化。" />

独立虚构前提：成年A与成年B并肩坐窗边长椅，A右手搭B左前臂。成年C已静立唯一入口D1；原文明示A先看到C，B随后循A目光发现C。先让观众在关系镜看见门边C，A/B仍交流；切A眼神由B移向D1；再用能理解A朝向的构图看B循目光转过去；C在门边回答。A的手可以一直搭着B；看C不等于松手或起身。

分别追踪接触对象、目光对象、话语对象，以及谁何时得到消息。拍到C不等于A/B已看见C，更不等于C听过此前对话。A—B转为A—C交流后，重新按新连线核机位；不必让三个人换位置来制造三套反打。

### 2.6 躺卧和靠肩：先理解支撑，再拍脸

半躺者的背靠在哪里，俯身者的重量靠哪只手或膝承受，两人的脸位于谁的哪一侧，先演得成立。拍俯身者近景时保留倾角和向下眼线，拍半躺者保留枕头/肩部支撑及向上眼线。要改成并排坐，先有可理解的退开、起身和坐定，或明确稍后的省略。

只在接触/支撑有歧义时注明左右手。让撑身手同时去抱人，需要先把重心交给其他支撑；剪到脸不会自动完成这个过程。附录B用拥抱演示接触关系怎样变成下一镜的首态。

### 2.7 本课练习

给定A坐桌左、B坐桌右，信已到B左手。试着只写B近景的机位与起始画面。合格答案应能说明相机仍在门侧、B看向A的方向、B仍坐桌右、信已接稳；不用再画整个房间，也不重新递信。若要让B站起离开，先把站起及可理解路线加入时间线，不能只改首态。

## 3. 表演与情感：把关系变化拍出来

### 3.1 先确定这段交流正在改变什么

从台词、行为、既有关系和完整前后因果确定角色想得到的回应，以及请求、试探、掩饰、安抚、逗弄等策略。**上下文支持的潜台词可以主动设计，不必等剧本标出情绪名。默认自然且让观众容易读懂；依人物性格调整，不无故演成夸张变脸。**

先核最近的有效触发，再确定情绪；同场可以由吃醋转为担忧，也可同时带着两种情绪，但要分别有依据。不能用本场开头的恋爱气氛解释之后所有冷脸。

| 虚构前后事件 | 如何判断与表演 |
| --- | --- |
| 已建立男方在意女方；她夸别人后，他立即收笑、冷答，中间无其他触发，后续仍围绕此人较劲 | 可主动按吃醋设计：手停、瞥她又避眼，原话短促带酸意 |
| 她夸别人；随后来人报告家中出了急事；他听完报告才冷下脸、追问事态 | 此次变化首先由急事触发，表现紧张、担忧或事态支持的严肃；不自动归为吃醋 |

内部记清支持判断的前后事件；证据相容就直接落实演法，只有会改变剧情理解且关键依据冲突时再集中问。情绪须落实为可见、可听变化。

重要交流内部核四件事：什么触发变化；怎样显露；对方察觉多少、怎样接收；下一镜接哪一阶段。稳定倾听、安心陪伴或暂不表态也可成立，不强迫每句话变脸。情绪可以由同一刺激持续作用或人物消化所见而渐变，不必每次增加外部消息。

例如源文明示或完整上下文支持他吃醋又不承认：听见她夸别人，整理纸页的手停一下；她询问时，他瞥她又避开，短答后压低声找借口。手停、避眼、读法共同指向嘴硬；不演成已醉、大发雷霆或公开告白。

#### 3.1.1 交给视频工具的文字，要写具体可见的表演

用户遇到过情绪词伴随日夜误变、眼神比喻被生成为发光眼球的情况。本节把画面措辞改得更明确；这属于针对当前反馈的设计，不能据此认定某个词必然导致某种错误。

内部可以理解文学表达，正式画面内容先译成具体的视线、表情、姿态和动作。普通人物的高兴、冷淡或失落，不用温度、颜色、光暗、火焰等比喻来代写。选与情境相容的一两项，不把整张表变成每镜动作清单。

| 内部表演意图/易歧义表达 | 普通人物画面可怎样写 |
| --- | --- |
| 听到好消息，“眼睛亮了一下” | 抬眼看报信者，眉间放松，嘴角扬起 |
| 对人冷淡，“冷冰冰的眼神” | 看对方片刻，嘴角平直；移开视线，原话短答 |
| 失望，“眼神暗下去” | 目光从对方脸上落到桌面，嘴角下落，原本伸出的手收回 |
| 愤怒，“眼里燃起怒火” | 盯住说话者，眉头皱起，下颌收紧；原话按怒意读 |

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/3cfdfd73a41a70bc5c7d83727523c6b1b353ecab/ai-drama-director-storyboard/assets/82-E-literal-performance.png" alt="8.2图E：表演意图先改为抬眼、嘴角与手部等可观察变化；时段和基准照明由场景单独确定。普通高兴不写发光眼球，冷淡不改白天场为夜景。" />

**日夜和照明写在场景条件，人物情绪写在表演。**每组继承已确认时段与光源：白天场保持相容的日间照明；窗外若入画，仍为白昼。换角度可产生符合原光源的明暗差，不能因人物不高兴就变夜、增月光或更换照明。换时段须由剧情或明确转场支持。

正式提示优先直接写正确的动作与场景条件，不把“不要发光、不要黑夜”等长串易歧义词反复搬进去。已有具体故障且必要时，才保留针对性的短限制。此处改的是导演画面说明；原台词/OS中的比喻照原话保留，不能搜索替换掉角色原句。源文明示真实法术、发光或变身时按特效事件处理，勿误改成普通表情。

### 3.2 一句台词可以有表达过程

台词栏写简短策略和必要读法：给谁说、重音落哪个原词、哪里收声、停半拍或被打断。普通直述无需套餐式标注。重音是语义着力，可以轻说，不等于提高音量；沿用角色既定音色，情绪变化不等于换声线。

推荐：`角色（画内/画外，策略；必要读法，重音：原词）：“原台词片段”`。OS另标内心声，不做口型。摄影说明不供朗读。

同一虚构原句“你就陪我一会儿嘛。”，要依据语境选读法：

| 源文已支持的表达 | 可执行读法 | 相容的可见表现 |
| --- | --- | --- |
| 软声请求陪伴 | “陪我”稍着力，末尾“嘛”轻收 | 转向对方、迎住目光，等答复 |
| 故作委屈，盼对方让步 | 音量收下，“一会儿”稍重，尾音轻落 | 原有笑意收些，肩略缩；没有依据不加泪水 |
| 有把握地逗他 | 节奏利落，句尾带笑，“陪我”着力 | 留意他反应，轻偏头；不统一演成怯弱 |

这些是不同前提下的备选。选中一种后，把转折绑定具体词或动作；不要整段轮流贴三种标签。原话照写，重音放括号内，不为拖音加字、重复音节或擅改标点。

### 3.3 情绪怎样跨镜继续

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/13d97d4f42ead9df37ba4004d64d4d72b2749ca8/ai-drama-director-storyboard/assets/82-A-emotion-bridge.png" alt="8.2情绪图A：虚构原文已明确周砚吃醋、许棠不知原因。放笔闷气、避眼否认、听到顾安手停、下一组抬眼审视依次发展；跨组延续的是闷气、停手和未答问题。" />

**让下镜从上镜结束时的状态继续，再写新变化；只明示影响执行的承接。**生气后的下一镜仍带余怒；闻讯后的担忧先露出来，再被借口掩住。切镜本身不把人恢复成默认笑脸或中性脸。

附录C的虚构事件：周砚因许棠夸别人而吃醋，放下铅笔说“你自己看。”；她察觉后追问；他避眼、拿手酸搪塞；她随口提顾安，伸向草稿本的手停住；下一组从停手、绷嘴接到审视。每一步的观测对象不同，但仍在发展同一段不满。

组头只需带与本组有关的首态，如`周右手停在本边、嘴角仍绷；许正等他回应叫顾安的提议`。逐镜写停手后的抬眼、指尖怎样落下，不重新放笔或重做同一次惊讶。

同一人正面近景→侧前方近景→回正面可用于观察原文支持的变化：前镜带笑请求，侧镜看笑意收住，回切看带着委屈接收回答。角度与构图应让变化更清楚；同脸同状态只换角度没有新增作用时，合并或换真正值得看的对象。

### 3.4 小动作从当前行为里选择

**人物均已确认成年，剧情已建立暧昧、恋爱或婚姻关系时，可以主动设计轻拉袖、挽臂、靠肩等相容互动，不要求原文逐项写出。**按人物性格、当场意愿和回应选择，接触有发起、接收与松开；不由此新增首次定情、吻戏、告白或和解，不把拒绝改成接受。

先利用手上和身体上已经发生的事：递物的手稍停、捏袖的指尖收紧、翻页停住、将伸出的手收回、从原有接触中松开。没有合适手部动作，就用视线、呼吸、姿态与声音。每镜突出一两项即可，不同时安排眉眼、嘴角、肩、手和脚全部表演。

| 已确定情境 | 表演可以怎样发展 | 须保留的事实 |
| --- | --- | --- |
| 撒娇求让步 | 带笑邀功→请求处尾音放软→若原文支持，再收笑装委屈；对方低眼看捏袖，再回应 | 哪只手捏哪只袖，何时抽回、何时松手；未获答不先演成功 |
| 关心却掩饰 | 听到坏消息，眼神骤紧、手指停→起身→被问才找借口 | 若笔已放下，用手离文书或按案沿，不能再放一次笔 |
| 原文有怒瞪后处罚 | 目光先锁到犯错者→短硬下令→对方接住命令 | 谁是发令对象、对方何时知道被罚；不替旁人补知情结论 |
| 留恋却嘴硬 | 原有物件唤起感受→神情一软→压住表情后说硬话 | 动作先于台词时须给它时间，不能从第一秒骂到尾把变化盖住 |

这些是选法，不是每场都插一次手部。小动作必须有关注对象和交流意义；道具不能为凑切镜临时出现。成人撒娇也不统一拖长尾音、眨眼、噘嘴或摇肩。

对话中也可主动安排有动机的调度：利用场内已有物件斟茶、收拾东西、坐下继续说，或走到窗边再回头；不必原文逐项注明。先核人物为何移动、手中物怎样处理、路线和经过时间，再把新位置交给后镜。调度须符合处境并保持原事件含义，不靠无目的走动填画面。

### 3.5 听者、OS和角色知情各归各位

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/13d97d4f42ead9df37ba4004d64d4d72b2749ca8/ai-drama-director-storyboard/assets/82-C-source-and-reaction.png" alt="8.2情绪图C：周砚的OS给观众听；许棠只能看见他停手和审视。OS期间可以拍她等回答，不能让她回答心声或把他的猜测拍成事实。" />

听者反应依据他实际听见、看见的内容。OS期间可以拍听者的外在状态，不能让他因此获得内心信息。

原文仅写他猜“她是等顾安”，就让画面表现他的猜疑；女仍等答，不能羞愧低头表示被拆穿。角色拿“手酸”“喝醉”找借口时，也不能仅凭借口就把它当作客观身体状态。

看见旁人不等于双方都已发现；入画不等于听过此前对话。接触对象、目光对象、话语对象和知情先后分开核，三人关系详见2.5。

甜宠按既有关系和当场意愿呈现；明示的发起与接收保留，未写明的普通互动按3.4设计。明确拒绝、疼痛或恐惧按原意表达，不改成害羞接受，不新增吻、告白或和解。

突发动作与渐进靠近的过程取舍，按3.5.2的明确前提判断。

#### 3.5.1 对话双方同时表演：没台词也有接收过程

**说话者表达时，听者也在听、判断和回应。关键刺激已经发生，却让听者从头到尾目光无对象、脸和身体无反应，属于表演缺项，必须修。**双人镜在同一时段写出双方有关的行为；切听者时让原声继续。无须等说话者讲完，才让另一人开始表演。

听者按“听到/看见什么→注意朝向→表情或当前动作怎样变化→如何继续”设计。目光可迎向说话者、追看其动作、害羞避开后再偷看，或因生气转开；明确对象与时机。不要只写“站在一旁听”。反应可在原话进行中发生，不能在尚未得到消息时提前知道。

下表均为不同的虚构明示前提，供选择演法，不是统一动作模板：

| 源文支持的听者状态 | 接收时可见的过程 |
| --- | --- |
| 成年恋人因对方夸赞而害羞 | 听到夸赞抬眼，笑意浮起又低眼；原本捏着衣角的指尖收紧，片刻再看对方 |
| 被错误指责而愤怒 | 听到指责，翻页的手停住，抬眼锁住说话者，下颌收紧；未到原文反驳处不抢加台词 |
| 对明示荒唐借口感到无语 | 看对方一眼，唇微张又合上，短呼一口气，目光回到手头事；不默认夸张翻白眼 |
| 本就赶去见人，得知对方将离开而急切 | 听到离开的消息，停下整理袖口，抬头看报信者；身体转向既定出口，是否迈步按原事件安排 |

动作只在已有姿态、持物和空间里选择，头、身、眼、手不必全动；克制角色也可以用有对象的眼神与呼吸体现接收。原文有意僵住、冷处理或故意不理人，就写清其触发与表现，不统一改成热烈回应。沉默、避眼也要有当下含义。

虚构原文明示女子被成年恋人夸赞、害羞而嘴硬，只有男方一句“今天这身很适合你”。成品可写：`男看向她，含笑说话；“适合你”入声，女抬眼与他相碰，随即低眼抿笑，原本捏衣角的手收紧。`男声按原句继续，不另给女子加一句“讨厌”，也不把同期反应另算一段时间。

自检关键双人交流时，分别只读双方行为：各自关注谁、接收到什么、怎样变化、后镜延续什么都应清楚。近景若看不到所需的听者变化，就切听者或调整构图；普通稳定倾听不必每句话变脸。

同样被夸赞，明确设定沉稳的人可短暂避眼后重新看回；外向的人可迎住目光笑开。两种是不同人设下的备选，不在同一人身上轮流套用。沿用角色已有表达习惯，再按当下目的改变策略。

#### 3.5.2 突发与渐进，提前给的信息不同

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/e2608a3defb31b3f25deb7fd06afd969ecb0aca2/8.3/ai-drama-director-storyboard/assets/83-H-surprise-and-gradual-action.png" alt="图83H：两个独立前提。突发喜剧先看人物正常工作，画外同事突然喊下班了，人物停手后笑着回头；渐进亲近则让成年恋人靠近、互相确认目光和迎接，再靠肩。不是所有动作都需要预告，也不是所有过程都应省略。" />

虚构前提一：成年职员正常看文件，画外同事突然喊“下班了！”，她一愣后笑着回头。若看点是突然被打断，先让她正常工作，不提前拍同事长时间蓄势或慢推门口；喊声出现才停手、回头。若源文要求观众先知道有人恶作剧，则可以提前交代，这时营造的是等待反应的期待，不再冒称完全突然。镜头预先朝某处移动，也可能泄露将发生的事。

虚构前提二：已明确相爱的成年恋人靠近拥抱。女方走近一步，等男方迎住目光并张臂，再靠入肩侧；男方接住并保持支撑。此处互相确认和距离缩短本身就是情感发展，不跳成“一切已抱好”。不增加原文没有的吻，也不把拒绝设计成欲迎还拒。

选择方法：原戏要观众何时知道、关键变化发生在哪、哪段过程带来情感，先答这三项再选镜头。图83H的两条动作链是不同源文条件下的演法，不要求每场各用一遍，也不规定相同秒数。


### 3.6 亲吻画面的3秒项目约束

**本项目默认执行用户指定的拍法：每段连续可见的嘴对嘴亲吻不超过3秒，允许正好3秒。**这是项目制作要求，不是平台统一审核条文；仍须完成0.4预检，不能据此保证过审。只在源文或已确认改编授权包含相应成年亲密时使用，不为示范拍法新增吻戏。其他项目采用不同明确要求时按该项目执行，不能悄悄解除本项目约束。

- **数的是接触画面，不是镜号。**从画面中嘴唇实际接触开始，到分开或切至不展示嘴对嘴接触的画面结束。镜内含靠近、亲吻、分开时，只有接触区间计入；例如5秒镜头内仅1—3秒接触，连续亲吻是2秒，不因镜长5秒就判超限。
- **换角度不重置计时。**正面亲吻2秒后直接切侧面继续亲吻2秒，连续展示仍为4秒，不合规；推近、慢放、换镜号或跨联合组也不重置。慢放按成片实际展示秒数计。
- **可以切开再切回。**在3秒以内切到有表达任务且不展示嘴对嘴接触的画面，如源文支持的握手收紧、旁人接收或可辨的分开后表情，再按剧情需要切回不超过3秒的亲吻画面。不要用一帧插图、短暂遮挡或没有观看价值的空景形式上断开，也不要反复循环亲吻镜头填时长；间隔长度由动作/反应能被读清决定，不另定统一秒数。
- **画外期间仍是同一次事件。**若接触尚未结束，回切承接其进行状态，不重新靠近、重新发起；若已经分开，之后再吻须符合源文或授权的动作含义。切手部时也要继承真实手部占用，不能让同一只手同时撑身和握手。
- **写清接触区间。**亲吻贯穿整镜，直接用该镜时间；只占一部分，在现有画面内容中短写“1—3秒嘴对嘴接触，随后分开”。自检把相邻镜和组界合起来数连续展示，不能逐镜各自报不超过3秒就放行。未看成片只能确认规划符合，实际生成超时仍须剪辑或重做。

**虚构剪辑例子：**源文明示两位成年恋人坐在长椅上自愿亲吻，女方同时握紧男方的手；双方空出的手足以完成动作。采用“0—2秒双人近景亲吻→2—4秒手部近景，握紧的动作继续，嘴部不入画→4—6秒回双人近景，承接同一次亲吻→6—8秒分开看向彼此”。两段可见接触各2秒，插入镜承接真实互动；8秒只是本例选择，不是所有吻戏的固定模板。不另加台词，不要求所有吻戏都切手部。

### 3.7 让同一个人物保持自己的表达习惯

**先判断他是什么样的人，再判断此刻怎样表达。情绪名相同，不代表动作、语气和外显幅度相同。**结合当前剧本、人物资料和前后行为，内部只记影响本场的习惯：通常怎样说话，如何处理距离与接触，受到刺激时先做什么，与当前对象是否有明确例外。不凭空补完整性格传记，也不把前一场的暂时愤怒变成永久性格。

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/main/9.0/ai-drama-director-storyboard/assets/90-D-character-and-expression.png" alt="图90D：感受、表达习惯、关系阶段与当前事件共同决定表演。独立前提下，清冷人物可停手、转眼、简短关心；外向人物可直接迎看和回应。高冷不等于无反应，没有剧情依据也不能套上调皮、脸红或噘嘴撒娇。" />

以明确设定为高冷、话少的成年女主为例：没有特殊剧情依据时，不自动设计调皮逗弄、噘嘴撒娇、害羞脸红或夸张摇肩。她也会高兴、担心和动摇，可让原本持续的动作短暂改变、目光留住、语气放缓，或用直接但简短的关心表达。若剧本明确她在男主面前有不同的一面，就按该关系特例描绘，而非为了维持“高冷”删掉原文反应。

| 源文已明确的条件 | 相容演法示例 | 不能擅自替换成什么 |
| --- | --- | --- |
| 清冷女主关心已交往的男主，仍不善直说 | 整理文稿的手停下，抬眼提醒吃饭；说完继续整理，目光短暂追他 | 无依据的脸红、噘嘴、拉人不放，或毫无接收的中性脸 |
| 稳重男主被误会，先解释而非争胜 | 看住对方，等其说完，平稳说原话；受伤感可留在呼吸与目光中 | 每次都握拳怒瞪、强拉对方或新增威胁 |
| 外向人物在源文明示的喜悦中主动回应 | 迎住目光笑开，按原关系靠近或回应 | 把这套幅度套给所有角色，或越过未建立的关系 |
| 同一清冷女主在当前情节被明确写为哭泣 | 保留哭泣，按当场原因安排身体与声音的变化 | 以人设标签为由删哭，或自行加出崩溃、和解 |

选择一两项能被当前取景读清的变化，接在已有行为上；没有手部任务就用目光、声音或姿态，不强造道具。小动作可以跨镜持续，不必每一镜重新“表现一次情绪”。对话双方各自按性格接收；冷处理、沉默或避眼也有对象和触发。

自检时问：去掉人名，这些动作是否能无差别放在所有人身上？若是，回到其性格、目的和对象重选。再核是否为了突出人设而改掉源文明示行为。人设与具体剧情似有冲突时先查上下文；确实影响理解又无法判断，集中提出具体疑点。


## 4. 切镜与时长：完整声音，变化中的画面

### 4.1 先确定看什么，再确定看多久

**本项目不设镜头数配额。为让原文情绪被看见，可以增加有效镜头；不为少镜头牺牲关键反应，也不为多镜头制造空转。**每次切换要能说清观众将新看到什么：停手、笑意收住、听者态度、未答时的等待、具体行动结果，或下一步所需的空间关系。

普通人物近景可先按约2—4秒试排，短反应、动作局部可更短；这与秒数强制切镜无关。约5秒以上再核后半段：是在持续发生变化，还是只有长台词压在脸上？有持续表演的长镜可以保留。连续换正侧角度却反复给同一张不变的脸，不能靠镜号增加解决平淡。

时间分配还要同时看变化量与动作难度：同样6秒，只握紧一次杯柄可能空转；起身绕桌、放杯、接箱却可能过密。先给必要接触与移动合理时间；简单变化完成后，可让同一段对白/OS继续，换看脸或听者的有效反应，不重复计时。6秒只是对照，不能据此否决所有6秒镜。

能在一镜中清楚读到双方变化，也可以留镜。关键变化在现有景别看不清时，才切近、切对方或切局部。镜数、景别和镜长都是表达选择的结果，不套全景→中景→近景循环。

当前用户偏好：约20秒的情绪起伏段，或容易平淡的两人对话，可优先考虑7—8个有效镜头，比五镜长留更丰富。切点找潜台词、接收和动作变化；不编新剧情凑镜，也不把所有20秒都硬套八镜。密度与生成分组分别处理，见4.6。

### 4.2 声音时长与画面时长分别规划，共用一条经过

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/13d97d4f42ead9df37ba4004d64d4d72b2749ca8/ai-drama-director-storyboard/assets/82-B-sound-coverage.png" alt="8.2情绪图B：附录C第二组12秒六镜，周砚OS按原顺序连续分配；画面依次看周、许、手、周、许、周。观察点变化不增加发声总时长，也不要求他人听见OS。" />

从源文提取实际发声的对白、OS和旁白，按读法估时。长句、数字/外语、低声、哽咽、抢话和重要停顿重点核；工具可统计真实发声字数辅助初估，姓名和动作括号不计入。没有试听时标明规划，不把统一字速或“低于某字/秒”当自然度证明。

一句话占0—8秒，听者在3—5秒反应，整体仍为8秒。放物、抬眼和说话若同期发生，只算一次；先放物、沉默、再开口，就按真实先后计。切反应不会缩短对白需要的时间，也不另加一次听者耗时。

附录C第二组把同一段12秒OS分配到六个观察点：周的疑心、许等待、手部压力、周审视、许找目光、周收住决定。原话未变，事件仍按同一时间向前。

### 4.3 跨镜声音要给准确片段

每镜“台词／OS”只写这一时段实际发声的片段。连续片段拼回原句，不增、漏、调序或重说；读法注明接上句，语气与音色连续。重音跟随包含该原词的片段，不标到尚未说到该词的前一镜。切画面时可以跨半句，不硬等句号；尽量在自然词组间分配文字，避免把一个词拆成难读的碎片。

同场对白切到听者时，原说话者画外继续，听者按其所闻反应，不做说话者口型。OS始终是内心声；发声者即使入画也不做口型。

**当前工作流主要保留Seed2.5生成原声。**同组内一句可跨多个画面，生成组界优先选一句结束、一轮答复或自然气口，避免为整数时长截断词语。必要跨组时各写实际片段、同一声源、接续语气和既定音色，提示本身不保证两次生成声线无缝。优先调整组界；有已确认音轨时才把覆盖作为可选补救，不默认用户会后期统一配音，见11.3。

用户可后期裁停顿、调音量、拼接已生成的合格对白、加字幕和屏幕文字；这些不等于默认重新配音，也不允许分镜先漏词或错归发声者。生成素材须留清楚的动作、气口与展示范围供剪辑，具体后期依赖用文件外短说明标明。

剪辑术语只作辅助：前一画面的声音延续到后一画面，可作L-cut式声画错开；先听后一画面的声音再切入，可作J-cut式提前入，参见[Apple的声音分离剪辑说明](https://support.apple.com/en-ca/guide/final-cut-pro/ver1632d82c/mac)。正式提示写谁、哪段声音、在何时画内或画外即可，不用术语代替执行信息。

### 4.4 用有效画面承接长句

判断当前正在发生的可看内容，再选覆盖：

| 画面选择 | 适用依据 |
| --- | --- |
| 说话者 | 这部分读法、表情或动作本身值得看 |
| 听者 | 正在接收、试探、等答或发生态度变化 |
| 手、道具、接触 | 当前动作承载情绪、决定或因果，且具体接点可见 |
| 双人/多人关系 | 需要看双方的距离、回应、牵拉或走位怎样同时改变 |
| 有信息的环境/空镜 | 交代时间、空间、声音来源、视线目标或原文所需的等待感 |

没有合适的手部就不硬插手，花瓶、烛火也不天然有用。情绪本身继续深化时，可以在脸上留够时间；根据实际变化选择，而非轮流填满这张表。附录C给一段完整可复制示范。

### 4.5 联合时长与整段节奏

单镜区间＝切入至切出的经过；组时长＝本组单镜之和；集时长＝各组之和。组内从0连续计时，切点可有小数，**每个联合组总时长必须写1—30的整数秒，含30；用户已确认的更小上限优先。**

2.4＋3.6＝6秒成立。合计6.8秒而只改组头为7秒不成立；应重排真实表演或分组边界，使区间恰好合计7秒。超过30秒就在可执行交接点拆组，30.4不能舍成30；不用凑满30，也不用静止等待补整数。精确区间是规划，实际生成按11.4复核。

整段还要有疏密：短促叫人、接收、迟疑和动作可以用不同镜长。压缩时先查重复动作、无功能反应、机械句尾停顿、可同期却排成先后的过程、无必要走路。保留发声后仍放不下，扩大合理规划或在已有授权内提具体删改方案，不统一赶词。用户指定时长与完整原文冲突，报告差额。

关键文字、照片或消息须给观众真正读清的时间；仅拍到手机或信封不能证明其内容已交付。手机消息、书信、文件可用原内容后期贴字，画面预留可读展示范围与时长，注明依赖；不擅加旁白代读，不把模型生字当准确成品。

### 4.6 剪辑密度与一次生成长度分别决定

用户当前实测反馈：一条20秒视频常从第8—12秒开始漏镜或出错。**8—12指视频内的秒数，不是镜头数，也不是工具硬上限。**据此优先尝试更短、交接清楚的生成组，不能因总长没超过30秒就认定执行稳定。

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/a175d4b207e1ed0cd550ea131639bd5b4cef8125/ai-drama-director-storyboard/assets/82-D-editing-and-generation.png" alt="8.2图D：20秒八镜的剪辑方案可拆成两个10秒生成组，每组四镜。单镜时长依次为2、3、2、3、2、2、3、3秒；第二组时间从0重计，事件、情绪和声音仍接前组。拆组为针对当前实测的试验选择，不能保证10秒生成必然稳定。" />

图D仅演示时间结构：20秒八镜可在有自然交接的第10秒分为两组，每组10秒、四镜。第二组从新观察点接同一事件；听者状态、接触与持物沿用，原声尽量在完整句或自然气口交接。不能仅切开数字而让两组重演，或留相同构图硬拼。

实际没有第10秒交接点，就移动组界、重排同期表演或选其他整数长度；仍不稳时再简化同组复杂动作、缩短试验组，保留有效切镜。7—8镜不等于必须一次生成。单组1—30整数秒仍是硬条件，图中的组长、镜数与切点均不是新配额；原声、动作和实际成片要一起核到末镜。

分组还要看本段具体任务：换发声者与画内外归属，较大走位/坐站转换，人物入场后换交流对象，换手/支撑，以及新机位需要交代的空间。先核这些任务怎样同时成立，再选择组界；简单八镜可能比复杂四镜更容易描述，但不能把它当成功率公式。复杂段可拆生成、保留成片切镜密度；无论怎样拆，组间位置、动作、情绪、日夜和声音接续均须成立。不能为降低一组难度而破坏相邻组衔接。

### 4.7 从单组好看走到整场、整集有情绪发展

先把联合组边界暂时拿掉，顺读本场已经发生的事情：开始时人物各期待什么，什么消息或行为改变期待，对方怎样接收，结束时关系、决定或未完任务留下什么。变化可以是明显转折，也可以是逐步加深、试探后确认或情绪被压住；不要求每场制造反转。

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/main/9.0/ai-drama-director-storyboard/assets/90-E-whole-scene-emotion.png" alt="图90E：附录J先被叫住而期待，得知只取书签后失落，听见还有再回望，收到吃饭提醒后回暖，最后离场留下牵挂。曲线标事件与关注变化，不是固定情绪强度分值或节拍配额。" />

附录J的虚构源文已明确：陆承以为岑霜叫他是要挽留，得知书签落下而失落；岑霜再提醒吃饭，他才感到被关心。把“叫住—期待—取物—失落—再关心—回暖—离场后余味”落实到动作、表情和声音。不能每个组都重新从平静对话开始，也不能为了增加看点另造误会、电话或第三人。

**增加小镜头时，先确定它在情绪发展中的作用：**

| 画面 | 在什么条件下值得看 | 该怎样接回当前事件 |
| --- | --- | --- |
| 手、衣袖、道具局部 | 它正在传达犹豫、收回、压力、交接或本场的关键认识 | 接动作阶段、持物与接收，不从头重复动作 |
| 无人物主体的环境空镜 | 门、窗外、通路或声音来源交代去向、等待与距离，或让前句情绪落下 | 时间仍在经过；回人物时继承已到状态与原声 |
| 听者或对方的短反应 | 对方获得了消息、态度变化或未答的压力 | 不提前知道，不把同一反应重演几遍 |
| 同一物件的后续状态 | 观众已经知道它属于谁、为何重要，其变化确实服务源文 | 清楚展示这一次结果；不凭物件新增秘密或旁白 |

手部、道具或人物局部不是环境空镜，二者都可以成为小镜头。氛围和消化情绪本身可以有价值；不是每个环境镜都必须揭示新线索。先看此刻是否值得停留，不以“丰富画面”为由机械插烛火、花瓶或走廊，也不统一取消有意义的停顿。

整集再顺读场与场：前场的余怒、担忧、承诺或疑问，后场是否在其实际知情与时间条件下继续？转场可以省略普通经过，不能把未完关键话或行动原因丢掉。集尾利用源文已经存在的决定、待答问题或期待；尊重原分集边界和用户授权，不为卡点偷偷增加危机、重排关键事件或改台词。

### 4.8 几种拍法都成立时，结合邻近镜头选择

先确定当前要看清的表演或行动，再看附近几镜已经覆盖过什么。**同样能完成当前任务时**，缺少细腻表情就优先考虑人物近景/特写；近景已连续出现，可换双人中景、空间上成立的过肩、关系镜或正在发生的细节，让观察有变化。不是“没有特写就必须补一个”，也不是每几镜必换景别。

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/main/9.0/ai-drama-director-storyboard/assets/90-F-neighbouring-coverage.png" alt="图90F：先确认本镜任务，再结合附近覆盖选择。同样成立时，缺表情可切近；近景密集可转双人或实际成立的过肩。要看脚步、双手接触或距离变化时，不能只为多样性裁掉关键过程。" />

独立虚构前提：成年恋人在门边道别，女方轻拉男袖求多留片刻，男停步答应。若前几镜已用全景/双人中景交代距离，可以切听者近景读出被打动；若刚连续拍两人近景，则用双人中景同时看拉袖、停步和接收也成立。过肩只有实际机位经过对方肩部才用，不为丰富镜型凭空加肩膀。手与脸要同时看清时，按2.4选择范围，不能只写“特写”却把动作裁出去。

源文、人设与已确认偏好足以判断时直接选择。不同拍法会改变剧情理解、人物态度或整场情感取向，而依据不足时，把具体差别集中问用户；不为常规每次切镜逐项请示。用户示例用于理解观看目的，不变成整部剧的固定镜头循环。


## 5. 第三课：动画衔接，接的是正在变化的动作

这里“动画衔接”指生成视频中身体、物件与表情的运动连续，也适用于写实或动画画风。本课教你选出下镜真正开始的阶段，不依赖复制上一镜尾帧来维持同一构图。

### 5.1 把一个动作理解成有先后的过程

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/441ceeadc047f287dac0a09284edc62699aeba0e/ai-drama-director-storyboard/assets/81-04-action-phases.png" alt="8.1图4：递信动作沿伸出、接触、接稳、释放、撤手单向发展；切在接触前后，下镜继续接稳，不再次伸出。" />

以递信为例：A持有→A伸出→B接触→B承重接稳→A释放→A撤手。全过程可以同镜完成，也可在其中一个阶段切近观察。**写下镜时，从上镜已到达的阶段往后接。**上镜手刚接触，下镜接握稳；上镜已松手，下镜接持有结果。摄影机换角度不改变“信属于谁、手是否还在动”。

可以剪在动作启动后或中段，使观众追着动作看；不必每次等动作全部完成再切。另一种同样成立的接法，是动作完成后切脸看接收。选择取决于本场看点及生成条件。[Adobe的连续剪辑说明](https://www.adobe.com/creativecloud/video/hub/ideas/what-is-continuity-editing-in-film.html)介绍了动作匹配与眼线等方法；本skill再把它们转为首态和过程的提示词。

### 5.2 动作接剪要带哪些信息

动作接剪按5.9推导，重点核当前动作的方向、阶段、速度和接触支撑；正式稿只写影响执行的两三项，不把内部演算表逐镜输出。

虚构两镜：`A右手把信推至B左手指尖，B开始握住`→`换到桌前门侧较近机位看交接，B左手握稳同一封信，A右手松开撤回`。下镜既继承接触，又出现完成；不写“再次伸手接过”。要保持手朝右移动，应说明这是当前机位的画右，或用“从A向B”这个空间方向；新角度出现合理投影变化时优先以真实路线判断。

**速度连续不是永远匀速。**冲过去接触时自然减速，拥抱落稳后呼吸慢下来；这由动作阶段解释。突然从急跑变慢走，需要剧情中的减速依据。不要为了生成稳定把果断动作一律改成慢慢伸手。

### 5.3 人暂时不在画面里，也继续生活在这一秒

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/441ceeadc047f287dac0a09284edc62699aeba0e/ai-drama-director-storyboard/assets/81-05-offscreen-time.png" alt="8.1图5：画面切B倾听时，A的话和合书动作仍按同一时间推进；再切回，A已经到达经过时间允许的位置。" />

切到B的脸，A仍在画外完成已安排的动作，声音也继续。再切回A，要问这段经过足以做到哪里。例如A在2秒听者镜内合上书，可以成立；从床内起身绕过家具到远门，不能用半秒空镜假装已完成。

省略是主动交代稍后状态，如“收好书→稍后两人已在门外”；实时接剪是同一经过。前者允许跳过无须观看的过程，后者须尊重过程的时间。写清选哪一种，观众才能知道发生了什么，不用把所有起身走路都逐镜拍完。

### 5.4 拥抱后为什么能换看另一个人

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/441ceeadc047f287dac0a09284edc62699aeba0e/ai-drama-director-storyboard/assets/81-06-contact-coverage.png" alt="8.1图6：双人镜先拍到A靠入B肩、B托住上背；拍B脸时保留A头部前景，拍A脸时保留B肩。两镜继承同一次拥抱。" />

独立虚构前提：两名成年人自愿相拥，A靠B自身左肩，B右手扶A上背，A外侧脸朝可被摄影机观察的方向。先用双人构图看到A接近并靠稳，B接住；切B近景，A头发成为前景、B目光落向A，扶背继续；切A近景，保留B左肩，A仍靠同一侧肩。前景具体落在画面的哪侧由机位决定，不应用相对而立的正反打口令硬套拥抱。图示是接触覆盖示意，实际以各机位几何核对。

换看A脸的价值，是看她如何接收安慰；换看B脸，是看他怎样回应。贴靠、呼吸、持物等状态延续，观众持续看同一次相拥。接下来若要分开，先拍清谁退开、手从哪里松开，再回两人对看；不能为了反打直接把拥抱变成一米间距。

### 5.5 转身、走动与路线怎样连续

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/441ceeadc047f287dac0a09284edc62699aeba0e/ai-drama-director-storyboard/assets/81-07-route.png" alt="8.1图7：A从窗边沿桌前通道到D1；侧向机位看到画右行进，门侧迎拍看到迎面靠近。屏幕方向不同，但真实路线相同。" />

虚构前提：A从窗边起身，沿桌前通道走向D1出门；B留在窗边。先选择可行路线，再放机位。侧拍看向画右走，改到门边迎拍可能变成向镜头走；仍沿同一通道接近同一扇门，不能因屏幕方向改变就判掉头。若下镜仍是同侧侧拍，却突然画左走，又没有转身依据，才需修正。

转身宜让观众看到开始或完成后的朝向依据。正面说完转身离开，可在肩背已开始转动时切侧后方继续转完，再随离开方向走；也可在关系镜里完成转身再切行进。不会强制“正面→背面必须插空镜”。

连贯奔跑可以用关系全景交代路线、近一点的运动镜看领先者与跟随者、再用门框或巷口确认进出；每次都核谁领先、牵哪只手、路线和经过，不把奔跑当作多张不同背景的跑步姿势。新空间另组，转角或换轴线用能被理解的调度交代。

#### 5.5.1 出画与入画：保持的是去向

先判两镜是否在接同一次连续行进，再用空间卡与机位推导画面方向。**以下常规接法的前提是：人物沿原路线前进，没有掉头；两镜都是侧向观察，摄影机留在行进轴线同侧，且没有明确的时间省略或新方向建立。**

| 上镜已经发生 | 下镜怎样继续 | 观众读到什么 |
| --- | --- | --- |
| 向画左走，从画左出画 | 从画右入画，继续向画左走 | 仍朝原目的地前进 |
| 向画右走，从画右出画 | 从画左入画，继续向画右走 | 仍朝原目的地前进 |
| 向画左出画，下一侧拍却从画左入画并向画右走 | 若无转身或路线改变的依据，应重排入画侧与去向 | 容易被理解成掉头返回 |

这里的左右都属于**当前画面**。人物自身左手、房间西端的门、窗边的座位不会随反打改名。下镜已将行进者收在画内时，可以直接接继续前进，不必为套规则再让他入画一次。

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/f8d5b3e44d64b39c58024735a9a48b3d2736c936/8.3/ai-drama-director-storyboard/assets/83-A-screen-direction.png" alt="图83A：俯视直廊D1在西、W1在东，人物由窗走向门；K1拍东段、K2拍西段，均在南侧朝北。对应侧拍先向画左出画，再从画右入画向左继续。改为D1门侧迎拍时，人物可以向镜头靠近；门与路线未变，不强套左右入画。" />

图83A先读地图，再读摄影画面：地图上方为北侧，下方为南侧；D1在西端，W1在东端。人从W1向D1走，K1在东段南侧、K2在西段南侧，两机均朝北拍，因此两镜都见人向画左行进。K1拍出东段，K2接入西段；附录E把它写成可逐组复制的完整稿。图83A底部迎拍是另一种覆盖选法；附录E后段从门内向门外拍，不使用该迎拍机位。

**方向改变可以成立，依据必须清楚。**换到D1门侧迎拍，同一路线会投影成朝镜头靠近；从门内拍与从门外拍，同一扇门也可能落在画面不同位置。先确认真实路线、门的同一性和新机位，不能单凭入画边判断穿帮。人物转弯、转身、摄影机连续移到另一侧，或关系镜建立新方向，也可让后镜改变画面方向。可用实际转身、随拍转角或必要地标交代，不机械插全景或空镜。

当这些依据没有写清、画面又像反向走时，优先改成易读的同向接法。不要只写“方向一致”；写成“由W1沿直廊向D1走，本镜由画右入、向画左继续”。真实路线与当前投影同时明确，才不需要执行者猜。此方法适用于同组切镜及联合组之间；[Adobe的轴线教学](https://www.adobe.com/in/creativecloud/video/discover/what-is-the-180-degree-rule.html)说明了保持空间方向及有意改变方向的摄影基础。


### 5.6 表情也是运动，有开始与继续

原文明示A听见拒绝由笑转委屈：笑着问→听到关键否定才收笑→带着已形成的委屈追问。切到侧近景可以观察嘴角收住，再切回正面时保留这一状态。下一镜已经委屈，就不重新从笑脸表演同一变化。

同样，接触后手迟疑再落下、听者抬眼再迎住对方、呼吸由急促到平复，都可成为有价值的连续变化。读法与可见行为配合见3节。当前构图看得清完整变化时，可以留镜；变角度要提供新的观察价值。

### 5.7 不靠尾帧重复构图的接法

上一镜尾帧用来确认“此刻事件到哪里了”。下一镜由同一人物资产、同一空间、这一刻状态和新机位重建构图。若是同机位连续延长，尾帧续接很合适；若要手部切到脸、双人镜切近景，不默认把手部尾帧强行当脸部首帧。

工具若只支持锁定首帧延长，用该路径就可能锁住视角；需要按实际界面改用支持新视角的参考方式或补新机位参考。写作智能体负责把需要什么说清，不承诺一个文字口令就让所有工具解锁。11节给素材分工和测试办法。

### 5.8 观察重点变化，不一定需要切镜

独立虚构前提：成年A/B在廊前交谈，成年C在同一纵深的D1门旁等候；原文写A发现C。机位能同时收前景A/B与后景C，可先让门边C清晰、前景稍虚，再把焦点移回A的眼神，A才转眼看C。人物没有走到新位置，摄影机也未切换，只有清晰区域与关注对象变化。这叫同镜头内转移焦点；提示词写成一个连续镜头，不把前后焦点误写成两个硬切镜头。

这只是一种覆盖选择：景深或生成控制不支持时，直接用关系镜→A发现的近景，事件同样成立。虚焦不是遮住身份错误的手段；先明确谁在门边、谁看见了谁，再决定用哪种拍法。

#### 5.8.1 见物、读懂、认出：三种不同的结果

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/e2608a3defb31b3f25deb7fd06afd969ecb0aca2/8.3/ai-drama-director-storyboard/assets/83-G-focus-and-readable-information.png" alt="图83G：同一六秒镜头，前段封面清楚、后段脸清楚；固定构图只转焦点。封面写周五15:00，东门。只有看见信封不能证明知道时间地点；关键信息需可读，文字可后期贴入平整封面区。" />

**见物**只确认有一封信；**读懂**需要人物读到内容，若观众也必须知道约定，就给可读信息；**认出**需要源文支持的识别依据，例如明示的独特封蜡或字迹。不能用一个通用白信封加“她认出是某人的”冒充视觉证据，不擅自加身份结论。

独立虚构源文：成年陆乔在收发桌拿起两封信，一封写同事“岑安”，一封写“陆乔”；她核对姓名，把岑安的放回，只带走自己的。先建立两封都在手中→让必要姓名可读→核对后放回错的一封→下一镜只持自己的一封。姓名已在原构图可读，就不强制另插特写。这个判断有看见、对照和行动的证据，不能只给惊讶脸让观众猜，更不能加“被背叛”或新OS。它与附录I是两个独立案例。

附录I明示封面“周五15:00，东门”，叶宁读后答“我准时到。”。若只拍她拿信抬头，观众只知道她收信；不能假定观众已经知道时间地点。用清楚的封面区域承载原文信息；重要文字可按已确认流程后期贴字，交付时写明准确文字和贴字位置，不承诺模型生成的字天然可靠。不把未给出的信件内容变成作者画外音。

图83G是一个连续镜头：固定中近景同时容纳脸与胸前信，先对焦封面，再移焦到抬起的脸。焦点变了，镜号不变。若实际工具不能可靠完成，可改成封面特写→人物近景的两镜同组；选择一种写进正式稿，不把两个备选都塞进一次生成。变化中的焦点要服务当前信息顺序，不拿虚焦掩盖人脸或站位错误。


### 5.9 从上镜状态推导下镜

把摄影机暂时拿开，人物仍应能在同一世界里行动。**下镜可以换构图；位置、动作、接触和情绪的改变，要能由真实经过解释。**内部按以下顺序推导，不把步骤表逐镜抄进成品：

1. **确认两镜关系。**是同一事件实时接续，还是明确的时间省略、换场或主观画面？实时接续不凭空增加时间；合理省略不强制拍全每一步。
2. **取上镜已经到达的状态。**只记影响下镜的站坐位置、面向、动作阶段、持物/接触、注意对象及未完声音。写了“已接稳”就不能回到“刚伸手”。
3. **演出接下来的变化。**谁继续动、朝哪个目的地、靠哪里支撑，另一人怎样接收；经过时间是否够用。画外者也按同一经过继续，不能借切镜偷偷换位或换手。
4. **放入新机位。**从固定门窗、人物连线或路线确定摄影机位置与朝向，再推导本镜的画左/画右、视线高低和可见范围。不能先写“正反打”，再让人物迁就构图搬家。
5. **选择值得看的变化。**把动作继续、听者接收或新信息放到确实看得见的镜头；准确安排原声片段。正式稿只留下这些执行结论。

以下是不同虚构前提下的判断，不把一行例子移入另一场戏：

## 6. 第四课：联合镜头分开生成，观众仍在看同一场戏

### 6.1 先排一场的剪辑，再决定生成组界

把当前场的事件、声轨和观察顺序排好，再在可执行的动作阶段、表演转折或场景变化处分组；当前保留模型原声，优先兼顾完整句或自然气口，按4.6针对当前实测选择较短试验组。联合镜头只是制作单位，观众不需要感觉到“这一条生成结束了”。总时长是1—30的整数秒，可正好30，不凑满；组内镜数与小数切点按内容安排。

正在失衡、手刚接住重物等状态很依赖精确姿态，优先保留在同组内完成；若必须跨组，写清具体接触/受力阶段并说明所需状态参考。**稳定交接点是降低独立生成难度的选择，不是让所有动作先停住才允许切镜。**同组内可以大胆在动作进行中切；独立两组在参考充分时也可以，但应先小范围实测。

### 6.2 交接什么，下一组才不会重新开演

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/441ceeadc047f287dac0a09284edc62699aeba0e/ai-drama-director-storyboard/assets/81-08-joint-handoff.png" alt="8.1图8：组1手部交接完成，信在B左手；组2切B中近景低头看信。机位与观看重点改变，持物、坐位和同一时刻延续。" />

在组末与下组首态间交接：身体位置，物件/接触阶段，表情/注意对象，声音及未完交流。只把本组执行依赖的状态放入现有字段。例如上一组刚赌气否认，下一组首镜仍带闷气；听到新名字手停后，可切脸发展疑心，不能重伸手或恢复平静。完整示范见附录C。

例如上组以`B左手接稳，A已松手撤回`结束；下一组场景参考可写`日·内书房；由门朝窗看A桌左、B桌右相向坐；机位留门侧。B已左手持信，A右手空出；直接接顾舟看信。`首镜换B中近景低头，既可独立复制，也不会重新递信。连续问题跨组时，另交接谁刚问了什么、谁未答；人物位置准确不等于问答没有丢。

### 6.3 上组末镜和下组首镜怎样形成有效的切换

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/441ceeadc047f287dac0a09284edc62699aeba0e/ai-drama-director-storyboard/assets/81-09-boundary-options.png" alt="8.1图9：双人中景结束后，可切听者近景、有效动作局部或有动机的关系新角度；同一双人构图硬接易跳，连续延长应作为一镜处理。" />

先把组界隐藏，单独看这两个镜头。上组第五镜是双人中景，下组第六镜优先接新的观看任务：听者接收的近景、正在发生的手部变化、与新对象有关的关系构图。若两个“双人中景”在角度、尺度、主动作、观察重点上都近似，独立生成硬拼很容易出现位置或表情跳变；合并为同一成片镜头，或重设计一侧。

**不能把用户指出的问题变成“相邻双人中景一律禁止”。**常规连续叙事里，同为双人中景，后镜有可理解的新角度、调度和观看目的，可以成立；连续延长的同构图片段也可接，但作为同一成片镜头的素材续接验收。名称相同不自动错，名称不同也不自动顺。

### 6.4 每组可复制，重复多少才够

组头集中写身份版本、地标和位置、关键持物/接触首态、本组相对时间硬切。逐镜只写变化与新机位。复制本组到空白输入时，仍能确定谁在哪、做哪一阶段；不靠“同上”“接原尾帧”来补关键信息。无场景图写导演拟定，不伪造图片名。

一组里的每镜都是真实切换；镜内推近仍是一镜。声音跨镜时逐镜分配准确片段，画外发声归属清楚；组界不重念、不加淡出/定格、不重启表情。原声独立生成断裂时，先查组界和声源；有已确认音轨才可用来覆盖，不默认后期统一配音。文本规划与实际声音试听分别验证。

### 6.5 把一场戏压缩成提示词的正确顺序

内部完成空间图、动作演算与切点判断→整理每组首态→写每镜当前可见变化与准确发声→删掉不会改变执行结果的解释。正式稿不写“导演想让观众感受到……”；直接写相容的语气、表情与接收。精简的前提是已经演通，详见7.1。

### 6.6 专门解决“上一组到B，下一组又回A”

**本组从上一组已经到达的状态开始；房间的初始布局不等于人物当前站位。**先辨别错误在哪一层：分镜本身把下组写回A，先修设计；分镜明确在B而视频回到A，再核本组引用素材、位置说明及实际生成，不能把两类问题混在一起。

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/main/9.0/ai-drama-director-storyboard/assets/90-C-handoff-at-B.png" alt="图90C：附录J中陆承从门内A沿桌前通道到窗侧B，拿书签后转头看门；下一组仍在B，身体朝岑霜，头先朝D1，再依还有回看她。相机换了不代表人回A；人物自身右手蓝夹、左手书签继续。" />

位置标签要绑定稳定地标。例如`A＝门D1内；B＝窗W1旁、桌T1东南侧`。只写“A/B”而不说明在哪，不能让独立一组恢复布局。另分清身体朝向、头部/目光对象及摄影机朝向，不能用一个“回头”代替全部条件。

9.0新写组头可用一行`人物位置／调度：`集中写每人的本组起态，以及有必要的路线与停点；用它替代场景参考里散乱重复的位置说明。没有移动也写清影响执行的当前位置。修订已可用旧稿时，原场景/道具参考若已完整说明相同信息，可以保留其格式，不为增加一行重写全场。无论放在哪个字段，每组都须独立清楚。

附录J的交接可简写为：

- 上组：`陆承从A沿桌前通道走到B站定，身体朝岑霜；右手蓝夹、左手书签。听门外短铃，头转向D1。`
- 下组首态：`陆承已在B，身体朝岑霜、头向D1；仍右手持蓝夹、左手持书签。岑霜留桌前。`
- 下组新变化：岑霜说“还有，”后，陆承才从看门转回看她。先继承，再发展；不重走A到B，也不因换成近景而回到初始构图中的站位。

身体已经到B但心情还失落，下一组也不能自行恢复笑脸；笑意要由后续关心触发。手里刚拿到书签，下一组不能又从桌上拿一次。组间交的是同一时刻的人、物、注意与未完交流，不只是地点标签。

**每一处组界内部这样核一次：**取上组末镜实际结果→与下组的场景、人物位置/调度、道具及首镜逐项对照→沿下组全部镜头确认没有偷回旧状态。文字说B、首镜却写从门口出发时，替换冲突句；不能在末尾再加“保持一致”让两条相反指令共存。

简易3D图或普通场景图只提供其明确表达的空间和时刻。用户明确要求制图时，可用固定布局配当前起态占位，路线目标以标记区分；不能把同一人物的起点、终点都画成两个同时存在的人。没有3D图也按文字首态完成此检查，不为修位置擅自追加制图任务。


## 7. 正式分镜格式｜9.0

按用户指定的骨架输出UTF-8纯文本：新写组头用“联合镜头、出场人物、场景参考、人物位置／调度、道具参考”，逐镜用“镜头N、景别、机位、运镜、画面内容、台词／OS”。**单镜时间、切点、必要环境声和承接放进现有画面内容；语气放进台词／OS；空间首态集中在人物位置／调度，场景参考写布局，持物放道具参考。已可用旧稿若在原字段已清楚包含相同信息，可以保留其骨架，见6.6。**不自行增加长表或额外顶层字段。开场/集尾说明如确有需要，放文件外的制作说明。硬切属于剪辑，组头统一注明；运镜栏写固定、推拉摇移跟等实际相机行为。以下是结构示意，交付时替换为实际内容；不填空模板冒充成品。

```text
《剧名》第X集（规划总时长X秒｜实际X镜）

联合镜头1（镜头1—N，时长X秒）
出场人物：实际入画者及必要外观版本；纯画外发声者在台词栏明确实名。
场景参考：场号/名称、日夜/内外；真实图片或具体缺项、稳定地标和可走通道；本场时段与基准照明。无背景配乐，现场声按剧情。
人物位置／调度：本组起点、坐站姿态、必要身体朝向与目光；本组路线/停点；影响当前表演的情绪余态与未完交流。只写执行依赖，不逐人抄全套清单。
道具参考：本组实际出现的物件及起始状态。

镜头1
景别：明确尺度。
机位：相对地标/人物/轴线的位置、朝向、必要前景和高度。
运镜：固定或有动机的运动；镜内运动不冒充切镜。
画面内容：组内0.0—X秒（本镜X秒）。承接的姿态/行为；观看对象、具体表情/小动作和变化；必要环境音。重要触发点可短引原词定位，其余由时段和动作确定；不逐镜追加切镜理由或镜尾交接清单。
台词／OS：发声者（画内/画外、简短语气与读法）：“准确片段”；有OS/旁白再明确归属与方式，内心声不做口型。无发声写无。

镜头2
逐项写全同样字段；不以“同上”替代。

```

组头“时长X秒”的X必须写1—30的整数，不写6.8或6.0这类小数格式；单镜时间与组内切点可保留小数。时间从本组0开始，连续到该整数组时长，逐镜相加必须严格等于组头数值；镜号在本集连续，各集可从1重编号，跨集引用带集号。画幅与画风由用户指定，不默认9:16或真人写实；已确认的规格与实际统一声源简写到各组，不擅填或换风格。精确小数是规划定位，不是模型精度承诺。

“台词／OS”只放本镜实际发声片段及简短读法；同镜有对白和OS时明确分项和各自起止，不把两者混成同一口型。连续一句跨镜，各片段拼接等于原句，不在不同镜重复全文。无对白镜不强造台词。OS/旁白来源沿用该剧本，信件文字不自动变成写信人旁白。画面内容中的音效按动作时刻触发，不靠每镜心跳、转场音代替情感。

为定位触发或切点，画面内容可以短引原词，如“听到‘不用你管’时手停住”；这只是时间/表演定位，实际发声仍只来自台词／OS栏。不得因此再朗读一次。画内/画外按本镜实际画面判断，不等于人物是否在同一房间；OS是内心声而不是画外对白，现场角色不能听到。

### 7.1 成品必须精简：输出执行提示词，不输出导演工作记录

**内部推演可以详细，正式分镜只保留生成必需的信息。**用最少的字讲清谁在何处、做什么、怎样说、何时切、下一镜接什么。原台词、必要状态和情绪变化保留。镜头可以多，每镜文字仍应简短明确。

- **组头写共同条件。**人物资产、场景地标、必要首态及统一切镜/声音要求集中写一次；每组仍可独立复制，不能靠“同上”省掉组间必需信息。
- **逐镜只写本镜差异。**时间段、主要动作/表情变化、关键承接或切点。机位用最短且可复现的位置和眼线描述；不逐镜重抄全场坐标、道具清单或全部在场者。
- **读法只抓关键。**保留能改变表达的一项语气、必要重音或停顿，配合有意义的表情/动作；不把一句话解释成一段表演理论。
- **删除推演和防错旁白。**“为什么这样拍”“不是某种感情”“不能听见OS”“不凭空多一只手”等通常留内部检查。成品直接写正确的动作与发声归属；确有歧义或已发生的模型故障，才留下针对性的短限制，不复制整份禁令。
- **交接只交关键状态。**首态和动作已明确，就不在每镜末尾重复长清单；组界只补下一组执行真正依赖、正文尚未清楚表达的状态。
- **交付前做删句检查。**删掉一句后，剧情、空间、表演、切镜和衔接仍同样明确，就删。删后需猜人物位置、手部道具或动作阶段，则保留或改成更短的明确句。不设统一字数上限，不压缩原台词，不为省字漏掉必要镜头。

#### 为什么要把教学与成品分开

过去冗长交付的可核问题：组头与逐镜重复地标/持物；把心理解释和切镜理由写进提示；用成串禁令代替明确动作；只核是否写了字段，未核哪些字能删除。改法是在内部做完判断，再保留执行结论。

虚构冗长句：“女方仍在沙发左边，她理解男方答应了，所以不是重新撒娇，也没有换位，我们要让观众看她高兴。”可改为：“女笑开，松袖改搭他右前臂，轻靠他的右上臂。”位置和左右手已由本组首态确定，删去推演后动作仍明确。

以下完整三镜以明示原文为前提：两位成年恋人并坐，男欲起身，女拉袖求陪伴；男答应坐回，她松袖靠近。对白只有“你就再陪我一会儿嘛。”“好，陪你。”。示例教如何精简，不规定每段都只拍三镜。

**精简完整示例（虚构，两位成年恋人，无现成资产）：**

```text
联合镜头1（镜头1—3，时长10秒）
出场人物：成年女方、成年男方，恋人。
场景参考：夜·内，客厅。沙发背靠墙；从茶几看，女左男右。两人并坐，男前倾欲起；机位均在沙发前，按时段硬切。无背景配乐，现场声按剧情。本组维持夜间原场照明。
道具参考：无手持物。

镜头1
景别：双人中景，收头部与拉袖处
机位：沙发前正面
运镜：固定
画面内容：0—4秒。女左手轻拉男右袖，抬眼挽留；男停住起身动作，切他回应。
台词／OS：女方（画内，软声；“陪我”稍重，句尾放轻）：“你就再陪我一会儿嘛。”

镜头2
景别：男方近景
机位：沙发前偏女侧，男看画左
运镜：固定
画面内容：4—7秒。男看回她，含笑坐稳；她仍捏着袖口。答应后切她反应。
台词／OS：男方（画内，温和带笑）：“好，陪你。”

镜头3
景别：女方中近景，带左手及男右前臂
机位：沙发前偏男侧，女看画右
运镜：固定
画面内容：7—10秒。女笑开，松袖改搭他右前臂，轻靠他的右上臂。
台词／OS：无。
```

以上长度是这段简单关系所需，不是复杂群戏的字数上限。学习它如何省掉解释并保留执行信息，不把人物、动作或秒数套进新剧。


### 7.2 执行验收：用正文证据，不用自检声明放行

**“已学习、已遵守、已自检”都不是完成凭证。**按以下过程制作与复核，内部保留简短定位记录，正式分镜仍执行7.1，不增加验收表或长分析字段。没有工具时也按同一逻辑核；不得假称运行过程序、试听或视频测试。

**先锁源文，再编镜头。**读取当前版本和用户授权，内部按原文位置列发声者、对白/OS原句及关键事件。教学、旧稿和后集内容不能替换当前基线。普通导演选择可以补动作过程，不能改变事件含义。源文明确的惊疑、拒绝、喜悦等反应不能随意换成另一种态度。

| 验收项 | 必须实际做的检查 | 发现问题后的动作 |
| --- | --- | --- |
| 原台词保真 | 从正式稿“台词／OS”提取实际发声片段，按剧情发声顺序和说话者/声源拼接，与源文逐条比对。跨镜片段合回原句；同镜多声源按已定先后核，重叠声分别核。重音标注、机位和画面短引词不计入发声。 | 未授权增删字、改字、错归属、重说或漏说必须修复。标点差异另核停顿和句意，不能把破折号误出的汉字“一”当标点忽略；原文错字无授权不擅改。有工具优先字符差异比对，仍核源文提取和片段归属是否正确。 |
| 事件与取景覆盖 | 将关键原事件逐项定位到镜号及可见/可听证据，按1.4核决定和转折，按2.4.1核作用对象、接触点与路径。 | 关键转折只在组头、动作只在取景外，都须修正文。可改取景、拆镜或合理省略；本来由声音交付的消息不强加画面。对白齐全不能替此项放行。 |
| 每组独立可用 | 临时只看当前组，从组头至末镜检查：必要资产/版本、地标、人物坐站位置/朝向、当前交流对象、持物和动作首态能否确定。每组都这样核，不能只查第一组。 | “连续同场、机位延续、人物在前”不能代替具体首态。缺图注明“未提供，导演拟定布局/待匹配资产”，不得伪造版本；把影响执行的缺项补入现有组头，一组一次，不逐镜重复。 |
| 动作与状态依据 | 逐对按5.9从下镜反查上镜：先判实时或省略，再核路线、机位投影、动作/持物/接触及情绪依据；进出画按5.5.1的适用前提判断，中间新事件另核触发。覆盖全部相邻镜和组界，换场则核真实转场关系。 | 修复无依据的移动、转手、坐站和重做动作。只有占用/接触可能冲突的手才明确左右；可成立的普通省略不硬拆镜，重要交接用一句明确过程即可。 |
| 情绪与覆盖 | 将关键交流顺读为触发→可见/可听变化→对方接收→后续状态，分别核说话者与听者，机位须看得见；关注原本5秒以上近景后半段及连续相似脸部覆盖。 | 关键刺激后听者仍全程无关注、无反应，按3.5.1补接收过程；情绪缺口补相容表演、听者或动作镜，允许增镜；同脸仅换角度未必有效。已放笔不能再放，OS不使他人知情。长镜有持续变化可保留，不用4秒硬上限放行或否决。 |
| 时长与声音 | 先按实际台词、具体读法、停顿和同期/先后动作估时，再核逐镜区间、连续性、组/集求和及1—30秒整数组长。嘴对嘴连续展示按3.6合并相邻镜及组界核算。 | 不能只调组头数字、赶词、删词或加定格凑数。长句加低声/转折/复杂动作的组合重点复核；切反应不减少台词所需发声时间。无音频只报规划与待试读处，不把字数阈值当自然度证明。 |
| 修复与精简 | 可修错误先替换，再追踪受影响相邻镜及后续状态，重核台词、位置、时间和组界。最后逐句检查删后是否仍同样明确；按3.1.1把导演画面中的光暗/温度比喻译成具体表演，原台词/OS不作词语替换。 | 去掉重复说明、推演和无关后文；保留原台词和必要衔接。用户只授权局部时锁定其他内容；缺源文、未授权改剧情或条件冲突如实定位，不虚报全稿通过。 |

**虚构验收反例，不能移作新剧情：**

- 原句“等我——我马上回来。”被写成“等我一我马上回来。”：多了发声汉字，不能按标点变化放行。
- 上镜助手双手抱箱、主角端杯，下镜主角双手抱箱离开：普通接续可写“主角放杯，接稳箱子后助手松手”；没有过程就不能只写“道具一致”。
- 只复制联合组2后，出现“她仍坐原位”：若该组没有说明原位在哪里就失败；补“她坐窗边长椅右端，面向桌旁站立的他”，不用重抄整间房。
- 近景只拍男方，画面却要求读清女方由笑转委屈：先把变化放到能看到女方的镜头，或合理改构图；不能用表情文字代替可见画面。

**交付判断：**台词、事件/权限、必要连续性、时间算术或本项目亲吻约束有明确错误时，不称“文本合格”；先修可修处。缺资料只能限定验证范围，不把缺少原工作记录直接判为原作者未检查。文件外用一两句报告实际核对范围、修复和未决项；只有对照完成才写相应项目通过。该流程提高可核查性，不保证所有模型一次遵守或成片生成成功。

## 8. 条件模块：只在需要时使用

本节的按需启用不适用于0.4节短剧审核预检；审核始终在每次制作分镜前执行，交付前再次落实检查。

- **人物/资产**：指定范围告知已提供资料内首次入画、首次新空间、换装妆发伤势等。前集可读就核前集；没核全剧不能声称全剧首次。组头实际使用正确版本。用户没要资产生成时不额外交付图片。
- **闪回/想象**：区分亲历记忆、客观补叙与想象；入口/回接明确时层与资产。角色没经历的事不冒充亲眼回忆，现实声音的延续要写清。
- **特效**：确有超自然/变身/复杂破坏时，记录触发、方向范围、过程、后果残留和资产，跨镜保持同一事件阶段。普通捏拳、推镜不用FX流程。无需无效空板块。
- **关键剧情**：用事件前后目标、知情、关系或行动条件的实质改变识别重要段落，局部给予足够表达空间。普通亲吻、场面大或台词多不自动决定集型/配额。
- **用户指定规模**：仅在用户明确选用时执行镜数/总时长条件，例如历史26镜或40—50镜、120—180秒。没有指定则按表达需要决定；发生冲突报告实际差额，不凑数或偷偷删情绪。

**条件模块的实际落地：**身份/服装/伤势变化建立“触发事件→新状态→适用镜段”，组头引用正确版本。多人/群像素材核实际人数、排序、母版和匿名配角差异；照片提及不等于人物进场。FX确需单独制作时给唯一事件编号，记触发、方向、范围、接触/作用、结果与残留，相关组引用同一事件及阶段；不能仅写“使用FX”让模型猜。闪回回到现实后接现实人物原状态，不能把过去服装带回来。这些只在剧情需要时执行，不要求所有剧输出全套模块。

## 9. 自检、修订与验证层级

按7.2对本次范围全部镜头、相邻镜对、组间及范围内跨集边界实际比对。先顺读事件，再从每个下镜首态反查上镜依据；7.2是核对方法，本节规定放行与报告，不再重填一套重复清单。

内部暂时遮住“吃醋、撒娇、担忧、委屈”等标签再读画面：仍能从触发、声音、表情或当前动作读出该状态，并看到对方如何接收，才说明标签已落实。这是内部检查，不要求从成品删除语气标注。若原文支持的关键情绪没有可见画面，先补镜或调整覆盖；不以字段齐全、镜头够少、每镜不到4秒代替检查。

修订先保护认可素材，沿被改状态的必要依赖检查前后：从原来如何进入本镜，到下游不再依赖被改状态的位置。局部修复不等于只改一个句子，也不等于整场重做；范围触及锁定内容时按0.1处理。

改构图或增减镜后，同步核镜号、组内起止、整数组长、台词/OS片段归属、持物、姿态和下一组首态。人物在下组是否返回旧初位，按6.6逐处核；情绪与动作是否仍属于这个人物，按3.7核；整场变化和附近覆盖按4.7—4.8核。

例如原组12秒，把6—9秒的局部延长1秒且其余内容不变，后段应移到10—13秒，组头改13秒；这段4秒不能冒充整组时长。压短手部镜后，剩余原声须准确转移到新画面，不能漏掉，也不让它从头重说。

交付当前范围能独立使用的修订稿，写清替换哪些组/镜；用户要求整场时合并局部修改，不让对方拼多个相斥补丁。正文移除已废弃演法，过程稿可另存。接已有视频按实际动作阶段选裁切点，不把某次约2秒的建议套给所有文件。缺源或未授权改剧情等实质问题具体定位，继续可完成部分。

区分四层证据：文字/算术已核；静态图实际看过；连续视频实际看过；声音实际听过。抽帧能查构图和位置，不能单独证明运动、口型、切点或语气。工具可比对白、编号与时间，不能证明情绪自然或生成稳定；未做的层级不称通过。

有成片时保留用户认可的有效表演。反复失败先定位具体原因，修相应层、简化实现或换有效覆盖，再建议小范围试验；不以新一句“已自检”鼓励重复付费。检查方向见11.4。

可修文本问题先修，再交指定范围完整UTF-8 TXT及短说明：修改位置、核对层级、实质依赖。工作记录不混入生成提示；能生成真实文件就给实际链接，不能时给完整正文并说明限制。

## 10. 群戏：先演通共同事件，再选择看谁

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/441ceeadc047f287dac0a09284edc62699aeba0e/ai-drama-director-storyboard/assets/81-10-crowd.png" alt="五人共用一张地图，按当前交流选择主持、索取者、交接双方与结果；裁出配角不等于配角离场。" />

### 10.1 主镜头、短关系镜与覆盖镜头，不能混用概念

**主镜头（master shot）**从头到尾连续覆盖一场戏的主要行动，供整体调度和剪辑参照；不只是开场拍一眼全景。**短关系镜**只用一小段交代此刻谁在哪、面对谁；地点已清楚时也可只交代新的关系。**覆盖镜头**从整体事件中选取说话、接收、接触、细节等观察点。主镜头可以运动，覆盖也不等于全部拍特写。

实际写法：先在内部把整场动作演通，再从中挑镜头。无需额外生成一条整场全景，也不要求每场、每组都先拍全景；已建立的关系可以由同一背景、视线或门桌地标延续。新人物进入、位置改变或共同反应读不清时，再给足够的关系信息。

这个区分依据[Adobe的主镜头与建立镜头教学](https://www.adobe.com/creativecloud/video/production/cinematography/camera-shots-and-angles/master-shot.html)。将整体调度用于提示词规划、按生成负担选择覆盖，是本工作流的应用，不是该资料给出的Seed2.5参数。

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/e2608a3defb31b3f25deb7fd06afd969ecb0aca2/8.3/ai-drama-director-storyboard/assets/83-C-master-and-coverage.png" alt="图83C：五人茶室先固定A后中、B桌左、C桌右、D左后、E右后门边。整场事件是开会、索册、交接、查看；短关系镜只交代位置，实际覆盖沿事件选人，不按五张脸轮拍。" />

**按图学：**A开场，B向C索册，C看向B后递出，B接稳，C松手，B查看。D/E仍在原处。先用短关系镜交代五人，再拍A开场→B索册→C接收→B/C交接→B查看，每个切点都有新任务。不能看图就让D/E轮流皱眉，也不能只剩B/C以后让A、D、E消失。附录F给出12秒六镜两组的完整执行稿。

### 10.2 按信息与行动选人，不按人数轮流分配镜头

先给每人写当前任务：谁发起、谁接收、谁回应、谁只是同场。未指定的配角可以保持自然注意、呼吸与已有姿态；“不添加反应”只是不虚构震惊、怀疑、结盟等含义，不是要求人定住不动。源文若写D反对，D的反对就必须被看见或听见，不能一直把他裁掉、虚掉。

每镜选完成任务所需的范围。交接必须看清手与物；听者变化重要时拍听者；共同反应本身是信息时保留多人同框。关系已经清楚且配角无新任务时，短双人、单人和细节覆盖通常足够。“不要三人中景”只有在用户当前项目明确限定时才是限制，不推广为通用规则。

出场人物列本组实际入画者，画外声音单独标归属；仍影响本组的画外人物位置和状态写进场景参考。减少无任务的同时正脸、交叉走位与多项接触，是降低提示词歧义的设计选择，不是人数与失败率的已验证公式。

### 10.3 分清变脸、换位与合法的新角度

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/e2608a3defb31b3f25deb7fd06afd969ecb0aca2/8.3/ai-drama-director-storyboard/assets/83-D-identity-position-projection.png" alt="图83D：身份、房间位置、画面投影分别核。B同一人同一椅子是延续；B脸变成X是身份错；B无过程移到C椅子是位置错；摄影机转到另一处使B落在不同画边，可以成立。示意头像仅代表已给定身份，不能证明实际视频面部一致。" />

每个主要人物绑定自己的面部、服装、音色参考及本场版本；衣色有助辨认，不能代替脸。再把人绑定房间中的椅子、门、桌侧与路线。最后按机位推导画面位置：**自身左右、房间位置、画面左右分别核。**同一个B坐在同一把椅子上，新机位可以把他投到另一画边；不能为了维持“B永远画左”搬动椅子或换人。

图中头像是概念标签；真实脸要对照实际素材检查。坐标只说明本例布局关系，不自动代表米数、焦距或可达距离。碰到画面变化，依次问：还是谁→还在哪→机位变了吗→变化有没有过程或重建关系。不能一见画左画右变化就判错，也不能一见衣色相同就判身份通过。

### 10.4 多人发现有先后，交流轴线也会随对象改变

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/e2608a3defb31b3f25deb7fd06afd969ecb0aca2/8.3/ai-drama-director-storyboard/assets/83-E-knowledge-and-axis.png" alt="图83E：何简在台左、陆舟在台右，孟宁早已在右后D1等候。观众先看见孟宁，何简随后发现，陆舟再循目光发现，孟宁才报告。三人未换位；主要交流从何简陆舟转到两人与孟宁，按新的交流关系选机位。" />

本例源文明示：何简向陆舟问“单子核过了吗？”，陆舟答“核过了。”；孟宁已在D1等候，何简发现她，陆舟随后发现，她才说“车在楼下等。”。观众看见孟宁，不等于何简和陆舟同时看见，更不证明孟宁听过此前所有话。

逐节点安排：问答建立何/陆交流→切孟宁等待，陆舟原声仍继续，只有观众先得到门边信息→何简目光从陆舟转向D1→陆舟循她目光看D1→孟宁报告。何简右手一直持原封口袋；她看谁、向谁说话与手中拿什么是不同状态。

主要交流对象转为孟宁后，以此刻人与人之间的新关系判断轴线。机位可以在旧何/陆轴线另一侧，却仍在新的“台边两人—D1”交流关系同侧；不能只拿最早一条轴线冻结整场。先用视线或关系镜交代注意转向，再切门边说话者。附录G给出固定坐标、机位和完整12秒五镜两组示例；不需要读者看过任何视频。

### 10.5 有人离场后，镜头留给谁

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/e2608a3defb31b3f25deb7fd06afd969ecb0aca2/8.3/ai-drama-director-storyboard/assets/83-F-stay-or-follow.png" alt="图83F：同一递袋离场事件，先看源文下一项任务。若任务是留下者收存文件，拍交接、离场方向、留下者归档；若任务是离场两人的后续交流，跟到新地点并建立关系。两条分支是不同剧情条件，不能混写成一个案例。" />

判断依据是**下一项未完成的剧情任务**。送件者离开，收件者还要看封面、归档，就留收件者；离开的两人有决定后续行动的交流，就跟他们。若源文留下悬念给室内者，镜头也可停留于其尚未结束的接收。不是“谁走跟谁”，也不是“永远留在主角”。

省略通常的几步路可成立，但不能把新决定、告别、突然折返等关键原因一起省掉。一个人出画后，其他镜头里的时间仍在经过；下次看回时按已经走过的时间继续，不能把他重放回起点再出发。合理省略与动作接剪的区别见5.3、5.9。[阿肯色大学《Moving Pictures》的剪辑章](https://uark.pressbooks.pub/movingpictures/chapter/editing/)分别解释时间省略、动作接剪与连续性；这里“跟谁”的选择按明确剧情任务推导。

附录H用“交袋→送件者离开→收件者归档”的8秒四镜，说明离场后仍留收件者的理由。图中另一分支只解释不同源文下的选择，不加进该例的正式提示词。

### 10.6 群戏交付前核的是事件，不是人数配额

按完整过程核：谁看见了什么、谁应有反应、交接是否真的完成、离场是否有路、画外者是否仍在原位置、下一组是否从已到状态开始。一个人已有明确任务却全程没有覆盖，不能用“少拍人更稳定”解释；无任务者也无需为凑镜数制造表情。

生成负担较高时，先减少无关人物同时入画、把独立反应分到不同观察点；复杂交接尽量同组完成。再按4.6在自然阶段缩短生成组；保持场景、姿态、手别、知情和未完交流。组短不等于剪辑慢，镜数多也不能代替因果完整。专业连续性工作还核道具、照明、动作、对白、时速和眼线，见[ScreenSkills相关职业标准SKSC32](https://www.ukstandards.org.uk/en/nos-finder/SKSC32/monitor-script-coverage,-continuity-and-technical-camera-details-during-shooting)。素材职责与缺项按11节处理。


## 11. 参考素材、声音与完整交付怎样落地

<img src="https://raw.githubusercontent.com/z2x7d54/ai-drama-director-skill/441ceeadc047f287dac0a09284edc62699aeba0e/ai-drama-director-storyboard/assets/81-11-reference-roles.png" alt="8.1图11：身份参考回答谁，场景与布局回答哪里，新机位构图回答从哪看，状态参考回答接到哪一步；文字还须明确道具持有和声音归属。" />

### 11.1 每组带齐对应素材，分别说明职责

当前用户每组会配齐本组人物、场景、道具等参考，提供了面部和音色参考的也分别绑定。写作智能体使用实际素材名与已确认引用方式，不能只在第一组说明，也不能凭文字名就声称已在工具里绑定。

| 材料 | 在本组负责什么 |
| --- | --- |
| 人物/服装图 | 谁入画、当前服装与伤势版本；角色全名与简称始终对应同一人 |
| 面部参考 | 对应角色的脸；与服装图一起核，不把另一角色的脸混入 |
| 音色参考 | 对应实际发声者；同一角色变情绪不随意换基础音色，OS仍归本人 |
| 场景图与布局 | 可见门窗家具、路线及人物位置；未见区域不冒充已证实 |
| 道具图 | 物件身份、外观版本和状态；正文另写谁持有、哪只手、接触阶段 |
| 新机位/动作阶段参考，确有时 | 从哪看、接到哪一步；不把旧尾帧强设成所有反打首帧 |

仅作命名格式示意，假设下列素材已提供：`出场人物：许棠（棠，女）；人物：许棠_常服.png；面部：许棠_面部.png；音色：许棠_音色.mp3。`实际替换为真实名称；这些内容留在既有“出场人物”字段内，场景图和道具图分别归原字段。纯画外发声归属在台词栏明确；上传了某人素材不代表他必须入画。未确认界面语法不杜撰@槽位或素材ID。

### 11.2 缺少场景或道具依据，保留剧情并括号标缺项

整场无图先按2.2确认已有信息并拟定布局；已有场景图中的局部缺项，按下述方法处理，不重复索取整场描述。

场景图没显示剧情需要的软榻、门或区域时，分镜按原事件编写，在本组相关名称后标`（缺少××）`，缺项写具体。例如原剧本写女方坐软榻，就保留为`女坐软榻（缺少软榻位置参考）`，不擅自换成婚床。摆放无法确认可标“导演拟定”，不能宣称原图有该家具；缺项在本组集中标一次，不因缺图停下整稿或擅自启动补图任务。

复杂贴靠、多人交叉、遮挡下换手或家具镜像，分别查身份、布局、机位和动作阶段；有必要可在文件外提出同房间新视角或白模需求。[Seedance 2.5官方说明](https://seed.bytedance.com/en/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5)介绍了多模态与白模参考，实际入口按用户工具确认。俯视PNG和文字地图不是几何锁定器，也不要求每场先建三维场景。

### 11.3 配乐后期添加，现场声随动作生成

当前背景配乐由用户后期添加，每组在场景参考内短写`无背景配乐，现场声按剧情。`脚步、衣料摩擦、落杯等按真实动作时刻和声源在画面内容中写；不每次切镜都配转场声。原文有现场演奏或歌唱时按原意保留，不能把它误删成后期配乐。

用户可后期剪停顿、调音量、拼接对白、加字幕及手机/书信文字。需后期的文字或声音用短说明定位到镜号，不把原对白完整性、正确发声者或情绪接续推给后期解决。画幅与画风由用户指定，不默认9:16、真人写实或其他规格。

### 11.4 一次交完整稿，再按真实失败原因修订

默认先完成文字自检，一次性交付指定范围完整分镜，以首次可用为目标；不把用户先试做一段设成交付门槛。收到反馈后保留有效部分，定位具体组、镜、时间与问题，再修对应层。

成片偏离原设计时，先说明实际偏差及其对剧情、连续性的影响。涉及保留素材、补接或重做的取舍，按具体片段和用户决定处理，沿用已确认选择；不预设全部接受或全部返工。写分镜时仍以当前确认的场景和状态为依据，生成后的取舍不能代替生成前的衔接设计。

| 用户已遇到的现象 | 优先核对与修法 |
| --- | --- |
| 后段漏镜、不再切换或镜序错 | 核区间、镜号、切点及镜内运动是否混写；降低同组并行动作，按4.6调整组长，保留成片有效切镜 |
| 人物变脸 | 核人物图、面部图、服装版与角色名的对应；减少无任务的多人正脸遮挡，不能只换座位解决身份问题 |
| 人物换位或瞬移 | 核地标、实际位置、路线、经过时间及组首态；不能只补“保持一致” |
| 动作重做、同构图跳变 | 核接触/持物阶段和组界观察重点，不重演已经完成的动作 |
| 台词漏字、错人或声音接续断裂 | 逐句核原话、发声者、音色参考、画内外与口型；优先完整句/气口分组，合格声段可后期拼接，不靠加速塞词 |

先对源文查事件是否漏编，再对原稿查是否写清，最后对成片查有没有执行；不能把设计层遗漏全归给生成模型。判断图像异常前，先辨认同一门窗、遮挡和持物：门已关但侧窗透光，不足以证明门重开；衣袖文字与当前采用的参考图不符可确认是资产描述冲突，不能据此断言某次变脸必由该词引起。按证据改对应层，不用猜测下结论。

这些问题用户均有遇到，不能预设只有镜数多一个原因。用户另行选择视频试验时，可核困难连续两组的实际人物、路线、接触、切点和原声；这属于可选验证。没有实际生成就说明只核了文本与素材依赖，不称视频已验证或保证一次成功。


## 12. 学会后做一次迁移练习，再交正式稿

### 12.1 新场景题：不套前面的房间

明确虚构源文：成年人林策站在雨棚下，成年人许棠从院中跑来，在他右侧停住。林策右手持伞，问“等很久了？”；许棠摇头，回答“刚到。”。林策把伞撑到两人头顶，许棠向他靠近半步；二人沿雨棚外通道离开。无第三人、无额外恋爱结论。

先用文字拟定雨棚入口、通道和机位侧；给两人的站位与可达动作；把问答、撑伞与靠近放进同一时间线；选观看重点，再分成两个1—30秒的整数联合组。每组独立复制，台词准确，身体靠近与手部持伞有依据。只在自然动作和观看需要的地方切，不要求照抄三镜或两秒节奏。答案可以不唯一，但每一处都应能从源文与空间方案解释。

**一种参考答案的演算：**由庭院朝雨棚看，D1在后墙、P1柱在画左；林策站门前面向庭院，因此他的自身右侧在当前画左。许棠从院中跑来，停在他的自身右侧。可用双人中景3秒看她停稳、近景2秒看林策提问、近景1秒看许棠摇头答话；第一组6秒结束时两人已站定、问答结束、伞仍收拢在林策右手。第二组6秒从双人中景直接看林策左手辅助撑开伞、右手举至两人之间上方，许棠靠近半步；转为侧后方全景时继续林策右手持伞，二人同向转身沿廊前通道向P1一端离开。两镜各3秒，只在伞已撑稳、两人靠近后换看行进。

对应问答准确写作`林策（画内，正常询问）：“等很久了？”`、`许棠（画内，摇头简短答）：“刚到。”`，不擅加“其实一直等你”。第二组仍须独立写本例地标、许棠在林策自身右侧、双方站定、伞在右手且未打开；不能只写“接上组撑伞”。伞开合方式和左手辅助是相容导演演法，示范的12秒须按实际读法和运动生成复核。这里给演算用于核自己的方案；正式提示词按7节字段整理，不混入这些理由。

### 12.2 对照题：能做对，也能识别何时可放行

| 给定情况 | 应说明的判断 |
| --- | --- |
| B接稳信后切中近景低头看，脸居中，仍坐桌右 | 成立：取景变、世界位置不变；信已到B手 |
| B接稳后，下组又从A手中开始接同一封信 | 修动作阶段：直接接持有结果，不重演 |
| A同侧侧拍画右走，切门边迎拍朝镜头走 | 可成立：核同一路线到同一门，不按屏幕方向字面误判 |
| A被拍到C后仍未看见C，下一镜才转头发现 | 成立：观众知情和角色发现分开 |
| A说话6秒，B反应在其中2秒，合计写8秒 | 修同期计算：经过仍为6秒，除非另有先后动作 |
| 相邻双人中景观看内容相同、独立生成硬拼 | 合并或换有效覆盖；仅修改镜号/名称无效 |
| 相邻双人中景已明确新角度、调度和观看任务 | 可成立：按几何与状态核，不一律禁止 |
| 上组含笑靠肩，下组从中性脸正站开演 | 修位置、接触与表情首态，不只补“连续” |
| 完整动作在一个清楚双人镜里完成，随后长留接收 | 可成立：核持续变化；无需强制拆成短镜 |
| 两镜各亲吻2秒，直接从正面切侧面继续 | 连续可见接触共4秒，按3.6修；换角度不重置 |
| 同一句从画内切听者，声音分配为连续准确两段 | 成立：听者不做说话口型，原句不重漏 |
| 原文明示吃醋，提示只有“生气地说”与普通对话脸 | 补触发、相容的可见变化及对方接收；不只加情绪标签 |
| 上镜已放笔，听坏消息后又写放笔以表现担忧 | 改用已空出的手停、离文书或按案沿，保持同一时间线 |
| 12秒OS改为六个有任务的镜头，原声音仍12秒 | 可成立：核片段完整与每镜观察价值，不把反应秒数重复相加 |
| 长近景拆成同脸同状态的三个近景 | 未解决：换角度不等于表演发展，按3—4节重新选覆盖 |
| PNG俯视图配了文字，声称已锁定三维位置 | 证据不足：只是空间意图，还需核素材绑定与实际生成 |

首次学习内部用本节判断题核理解，之后按当前问题回读对应课；不把练习答案或长解释混进正式稿。雨棚题指定两组是为了练交接，真实任务不套组数。

**再做两个辨别题：**手部特写完整收两手、布和擦拭路径，应允许它拍清擦镜，不强制切脸；原文关键决定已拍清，后续普通步行可以合理省略，不强制拍全程。反之，若下组只靠“已经折返”跳过原文明示且本场要表现的改意，就回到1.4补转折。能放行合理简化，才算学会而不是多加禁令。
