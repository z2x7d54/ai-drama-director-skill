# AI Drama Director Skill · AI短剧导演 Skill

**Latest: 8.3 · Author: mr zhu · [中文](README.md)**

Turn scripts into concise storyboard prompts, one multi-shot generation group at a time. The course teaches coherent space, action across cuts, emotional performance, and dialogue. Each version's complete Markdown contains its teaching, figures, worked examples, and checks.

## Start

1. Give a writing agent the [complete 8.3 Markdown](8.3/ai短剧导演skill-8.3版.md), your script and scope, using the [startup prompt](8.3/8.3启动指令.txt).
2. After the agent checks its storyboard, copy each complete generation group and its corresponding references into the video tool.
3. Read the [PDF](8.3/AI短剧导演skill_8.3_跨设备阅读版.pdf) on another device, or download the [illustrated ZIP](8.3/AI短剧导演skill_8.3_图文完整版.zip) for offline storage.

Each version has its own Markdown, PDF, offline HTML, ZIP, startup prompt, review instructions, and supporting resources. Native installation entry: [8.3/ai-drama-director-storyboard](8.3/ai-drama-director-storyboard/).

See each version's folder for its features and validation scope. Retain attribution **mr zhu** when sharing or quoting this work.
