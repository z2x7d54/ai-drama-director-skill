## 8.1教什么

1. **导演一场事件：**先读懂原文，演通动作、声轨和观看期待，再选镜数与切点。
2. **人物空间：**用地标、站位、身体朝向和可行路线确定同一空间；区分房间位置、画面位置和人物自身左右。图示演示同一地图如何得到双人镜与近景。
3. **动画衔接：**动作按接触、接稳、释放等阶段前进；换角度后接着演，画外经过也计入同一时间。另讲拥抱支撑、转身走动和表情延续。
4. **联合镜头：**先排一场戏，再分生成组；组界交接身体、物件、情绪及未完成交流。每组可独立复制，首镜选择新的有效观看重点。
5. **素材与群戏：**身份、布局、构图和动作参考各司其职；多人同场保留地图，按当前交流选择覆盖，不强迫每镜所有人露脸。
6. **完整示范：**书房递信、廊下拥抱与发现来人，分别给源文、导演演算、可复制提示词及逐对讲解；新场景练习检验能否迁移。

共14张教学图，其中12张为8.1新增原创示意。原文保真、语气重音、小动作、声画共用时间线、审核预检和精简交付继续保留。每段联合镜头总时长为**1—30的整数秒，允许30秒**；单镜切点可用小数，求和必须一致。连续可见嘴对嘴接触不超过3秒，换角度或跨组不重置；这是本项目拍法要求，不冒充平台通用条文。

## 怎么开始

把完整版MD和当前剧本一起发给智能体，注明制作范围、已完成内容及已有素材，再发送[启动指令](8.1启动指令.txt)。只复制正式分镜中的每个联合镜头到实际视频工具；教学解释和自检报告不混进生成提示词。

> 请使用《AI短剧导演 Skill 8.1》制作所附剧本【集数或镜段】。先读取源文并完成审核预检，按教学演通空间与动作，再输出可逐组复制的精简分镜。逐对核人物位置、动作阶段、声轨与组间切换；原台词准确保留，联合组长为1—30的整数秒。疑似压缩缺口按提供或授权的原著核实，不凭猜测补剧情。
