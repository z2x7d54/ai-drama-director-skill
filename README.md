## 8.2教什么

1. **情绪跨镜发展：**触发、可见变化、对方接收、下一镜状态；嘴硬、撒娇、担忧和误会都有明确依据。
   对话双方同时表演：听者的目光、表情与当前动作响应实际所闻；害羞、愤怒、无语、急切均有虚构例子，不站着等台词。
   完整上下文支持的潜台词可主动判断，先排除中间新事件改变触发原因；已确认成年且有暧昧、恋爱或婚姻基础的小互动可按关系设计，默认自然且情绪易读。
2. **长对白的画面覆盖：**保留完整声音，按实际看点选择说话者、听者、手部、关系或有信息的空镜；同期反应不重复加时。
3. **人物空间与动作：**区分真实位置、画面左右和身体左右手；持物、接触、支撑、画外经过都沿同一事件继续。
4. **独立生成组的交接：**空间、动作、情绪和未完问答一并带入下一组，首镜选择有用的观察点。
5. **完整示范：**递信、拥抱与发现来人、新增的画室吃味与OS覆盖，均有虚构源文和可复制提示词，不依赖外部样片。

正文15幅教学图，其中4幅新增；全部方法在MD里自包含。每组生成时长为**1—30整数秒，含30**，组内切点可小数但须准确求和。普通近景可先约2—4秒试排，持续表演可长留；镜数和秒数不是配额。连续可见嘴对嘴接触≤3秒属于本项目要求，换角度或组界不重置，不冒充平台统一条款。

当前主要使用Seed2.5生成原声。情绪密集段或容易平淡的对话，可考虑20秒7—8镜；图D说明这些成片镜头怎样分成较短生成组。用户反馈20秒视频常在8—12秒开始漏镜，这是当前制作实测，不能当作工具硬上限或成功率结论；拆组须兼顾原声气口、动作与情绪交接。

## 怎样使用

发送完整版MD、当前剧本、制作范围、已完成范围及已有资产，配合[启动指令](8.2启动指令.txt)。智能体按7节交付精简执行稿；每次把一个联合镜头连同组头完整复制给视频工具。教学解释和验收记录放在提示词之外。

原文保真、每次必做的审核预检、剧本压缩缺口查证、群戏覆盖、跨设备图片与精简交付均保留。8.2修订了方向混淆、入口标识、情绪变化的过强条件、运镜与剪辑混写等表述，合并重复检查；具体见[升级说明与验证记录](8.2升级说明与验证记录.md)。
