# AI短剧导演 Skill 8.0

**简体中文** | [English](README.en.md)

将剧本转化为适合按联合镜头逐段生成视频的分镜表。面向 ChatGPT、DeepSeek 等智能体，重点讲清人物空间关系、情感表演、有效切点和联合组衔接。

署名：mr zhu。当前版本：8.0。

## 这个 Skill 能做什么

| 功能 | 具体作用 |
| --- | --- |
| 剧本转分镜 | 按指定集数整理剧情与原台词，区分原文事实、导演补充和待确认信息，生成可制作的完整分镜表。 |
| 人物空间与机位 | 写清门窗、家具、人物站位、朝向、视线、轴线及移动路线，让换角度后的画面仍属于同一场戏。 |
| 镜头与组间衔接 | 延续动作阶段、接触关系、手部道具、声音和未完成的交流，避免每次换镜重新摆人、重新演一遍。 |
| 语气与细节表演 | 把必要重音、停顿、语速、表情变化、小动作与对方反应写进分镜，改善念稿式台词和站桩表演。 |
| 剪辑与节奏设计 | 根据剧情信息和情绪变化选择切点，安排反应镜头、声画衔接与疏密变化，避免机械地每5秒切一次。 |
| 联合镜头提示词 | 为逐段生成视频组织可独立复制的联合镜头，包含人物、场景、道具、逐镜内容及交接状态；每组总时长为1—30秒整数。 |
| 群戏调度 | 区分人物身份与位置，明确交流对象、主次和离场顺序，减少无功能的多人同时动作，并检查换位、视线及身份一致性。 |
| 制作前审核预检 | 每次制作或修订前核对适用审核依据、剧情表达及潜在问题，再落实到画面方案。 |
| 分镜自检与修订 | 检查原文保留、空间、表演、镜头衔接及时间求和；长对话后可用独立自检文档重新核对。 |
| 图文教学 | 提供17张示意图、明确前提的虚构例子及完整分镜示范，帮助未看过参考视频的智能体理解规则。 |

适合的流程：**剧本 + Skill → 智能体生成分镜 → 每个联合镜头交给 Seed2.5 等视频工具 → 剪辑与成片复核**。

## 使用方法

1. 上传完整 skill 与需要制作的剧本，说明实际集数、已完成内容及现有资产。
2. 使用启动指令要求智能体实际读取 skill，并在制作前完成本次短剧审核预检。
3. 收到分镜后，将每段完整联合镜头分别交给视频生成工具；查看生成结果后再剪辑、复核。

可用的简短指令：

> 请实际读取我上传的《AI短剧导演skill 8.0》完整版与剧本，按8.0制作我指定的集数。先执行0.4节审核预检，保留原台词与事件，写清人物空间、手部道具、表演读法、切点及联合组交接。每个联合镜头生成总时长必须为1—30秒的整数，包含30秒；单镜时长和切点可用小数，但逐镜求和必须严格等于组头整数。完成后按skill自检并交付完整TXT分镜表。

## 核心规则

- **精简成品**：内部推演可详细，交付给视频工具的分镜只保留生成必需信息；共同条件写在组头，逐镜写变化，保留原台词与关键衔接。

- 先理解整场交流，再固定门窗、家具、人物位置和动作路线；换机位继承同一事件状态。
- 台词配合明确的表达任务、必要重音、表情或小动作和对方接收，避免站定念稿。
- 按内容决定镜数和节奏，不默认每镜5秒，不固定整集时长或联合组数量。
- **联合镜头生成总时长必须是1—30秒的整数，允许正好30秒，也可更短。**逐镜时间线必须与组头一致，不能只将组头四舍五入。
- 每组可独立复制，交接人物、道具、声音、知情和未答问题，不将上一组尾帧作为所有新机位的唯一输入。
- 群戏分别管理身份和位置；保留必要关系镜，减少无功能的同时动作与多人正脸。
- 每次制作或修订前完成审核预检，交付前核对落实；剧本原句不等于可以无限细化画面。

- **实际验收**：逐条比对原台词，每组脱离前组检查首态，从下镜反查位置和持物，修复后再核受影响镜段；自检声明不替代证据。
- **本项目亲吻拍法**：连续可见嘴对嘴接触≤3秒，换角度/联合组不重置，可切有意义的非接触画面再切回；这是用户制作要求，不是平台统一条规。

## 文件与图片

单独发送主MD即可给智能体提供完整规则和教学文字；图片改用固定版本的HTTPS地址，支持外部图片且联网的预览器无需本机图片目录即可显示。部分聊天预览器会阻止外部图片，智能体也未必会读取链接；图片链接正常不代表接收方已看见。

人阅读或转发到手机时，优先使用图片已内置的PDF；也可将单文件HTML下载后用浏览器打开。两者无需联网获取图片。完整ZIP内另保留使用本地图片路径的MD和原生skill目录，离线查看MD需完整解压。PDF、HTML均由同一份完整版生成，包含三份教学附录和全部17张讲解图。

本仓库包含 skill、虚构教学示例与讲解图片，不包含具体项目的剧本、小说、分镜成片或本机凭据。规划时长与文字检查不代表视频模型已实测，也不构成平台审核通过保证。
