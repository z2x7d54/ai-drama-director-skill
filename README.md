## 开始使用

1. 将[8.3完整版MD](8.3/ai短剧导演skill-8.3版.md)、剧本和制作范围一起交给ChatGPT、DeepSeek等智能体，配合[启动指令](8.3/8.3启动指令.txt)。
2. 智能体自检后输出精简执行稿；把每个联合镜头的完整内容及对应素材交给视频工具生成。
3. 手机看图可用[8.3图文PDF](8.3/AI短剧导演skill_8.3_跨设备阅读版.pdf)；离线保存可下载[8.3图文ZIP](8.3/AI短剧导演skill_8.3_图文完整版.zip)。

各版本文件夹分别收录完整版MD、PDF、离线HTML、ZIP、启动指令、自检文档及该版配套资源。原生Skill安装入口：[8.3/ai-drama-director-storyboard](8.3/ai-drama-director-storyboard/)。
